出版商备注

1961年,Shrii Shrii Ánandamúrti——Ananda Marga的创立者——在贾马尔普尔那座Ánandamúrtijii及其信徒们常去的老虎坟旁,通过一系列夜间会议,将原始的孟加拉语版Ánanda Sútram口述给了一位亲密的信徒。 那位信徒在蜡烛的光亮下写作。 有时,蜡烛的火焰会被玻璃酒杯遮挡,从而充当一种临时灯笼。

Ánanda Sútram 的含义之一,就是 “那些能够引向 ánanda,即神圣幸福”的格言。 几个世纪以来,sútra这种形式一直被视为一种强大的工具,能够以简洁且易记的方式传达深刻的哲学思想。 sútra的字面含义是“线”,这意味着许多智慧的珍宝都可以被串在这根线上。 秉承 sútra 文学的传统,本书中的八十五个 sútras 以令人惊叹的简洁性,为整个 Ananda Marga 思想体系提供了框架。

在此,Shrii Shrii Ánandamúrti仅用寥寥数笔,便为人类提出了关于形而上学、认识论、伦理学以及宏观历史的独到理念。 他首次提出了一种基于有神论哲学的社会经济理念,将主观方法与客观调整相结合,从而为世界打造出一个以经济正义为基础、结构严密且不断进步的社会体系。 他将Ánanda Sútram与配套书籍Idea and Ideology视为Ananda Marga的darshan shástra (哲学论著)。

Ánanda Sútram整体此前仅以一个英文版本出现过,即由Shrii Manohar Gupta (1990年几乎未经编辑便重新出版)于1967年翻译的版本。 第4章被重印于1993年的Discourses on Tantra Volume 1中,而重新翻译后的第5章则刊登在1992年的《普劳蒂斯特经济学》上。

本版的编辑们并未试图重新翻译,而是根据对读者而言重要的若干考量,对第一版(或者就第五章而言,为1992年版本)进行了编辑。

本版的编辑们首先力求更严格地遵循作者对重要梵文术语的用法习惯,将这些术语保留在译文的主文中,而有时则将对应的英文术语置于编辑用的方括号中。

编辑们还试图消除梵文与英文对应词对中不必要的重复。

编辑们所考虑的其余因素包括语法方面——在那些必须进行修正的地方进行修改,以及一致性,例如在各种哲学术语的使用上是否使用冠词方面的一致性。– 在第1章至第3章中,仅有极少数情况需要通过重新翻译句子来提升准确性,例如第1章的最后一句话。 (在上述最新汇编中的第4章和第5章,除第5章中将梵文中的“yuga”译为“age”而非之前的“era”之外,其余部分均未进行重新翻译。“Age”似乎是作者在英文写作中更偏爱的表达方式,正如《理念与意识形态》中所体现的那样。)

编辑所加的脚注均标有 “–Eds.” 的署名。未标署名的脚注则为作者所加。

文本中的方括号 [   ] 用于标示编辑的翻译内容或其他编辑添加的文字。 圆括号 (   ) 表示作者原本给出的一个或多个单词。

在本版中,编辑们添加了一个附录,其中提供了sútras的逐词翻译。 Avadhútiká Ánanda Mitrá Ácáryá因多年前为这份附录奠定了基础而值得特别提及。

在附录中,本书作者采用了一种特定的缩写方式来解释单词的词源。 在该系统中,减号 (–) 位于前缀之后,而加号 (+) 位于后缀之前。 因此,可以理解为 ava – tr + ghaiṋ = avatára,“以 ava 为前缀、以 ghaiṋ 为后缀的根 tr 会变为 avatára。”

第1章

1-1. Shivashaktyátmakaḿ Brahma.

[Brahma是Shiva与Shakti的复合体。]

含义:Brahma [宇宙实体]是Shiva [意识]与Shakti [操作原理]的复合体。

一张纸有两面。 尽管为便于讨论将其视为两个,但它们仍无法与那个单一的论文实体分开。 去掉纸张的一侧,就会危及另一侧的存续。 在宇宙实体中,Puruśa [意识]与Prakrti [操作原理]之间的关系也是如此。 没有哪一个能够脱离另一个而存在。 正因如此,人们才说它们是密不可分的伴随物。

尽管作为哲学术语,shiva或puruśa也被广泛使用,但在日常用语中,具有相同含义的átmá [“灵魂” 或 “自我”]的使用更为普遍。 Shiva 的含义是 “见证意识”。 puruśa和–也是如此,puruśah的意思就是“存在于每个实体之中的、处于静止状态的见证力,而那便是puruśa。”另外,átman的意思是“具有全心灵感应能力的存在”。

身体的感官体验会被传送到心灵层面。 换言之,当原始的物理波撞击到心理层面后产生的反射作用,会唤醒心理层面中的感官意识。 以同样的方式,当物体的波动撞击到心灵层面并产生反射之后,每个粗糙物体的感觉也会立即在心灵层面上被唤醒。 相同的脑电波作用于灵魂实体,从而引发这些脑电波的反射,进而使该单元意识到自己与灵魂是不可分割的。 用哲学的语言来说,如果将心理波动,也就是思维,称为思维波,那么这些心理波动在灵魂板上的反射就应当被称为心灵波。 因此,就灵魂板而言,我们可以说它与心灵之间存在心灵感应。 所有寻常的事物,无论是粗糙的、微妙的还是具有因果关系的,都由心理波动或思维波动构成;因此,完全符合推理与逻辑,我们可以将灵魂称为具有全息心灵感应能力的存在。 正因有了这种具有全知通灵能力的Átman,所有有形或无形、庞大或微小的普通物体才得以获得事实依据与认可。 如果没有Átman,万物的存在都将面临威胁。

1-2. Shaktih Sá Shivasya Shaktih.

[Shakti (操作原理)就是Shiva的shakti (力量)。]

大意:每个物体都有物质因和动力因。 除此之外,还有一种连接机制将 upádána kárańa [直接原因] 与 nimitta kárańa [有效原因或工具性原因] 相连接。 决定物质因与有效因之间关系的紧密程度或松散程度,取决于二者之间关联功能的强度。 在创造过程中,Puruśa是物质因素,而Prakrti则是连接力量,用以确立物质与有效原因之间的关联。 作为根本原因,Puruśa是主要因素,而Prakrti则是次要因素。

Puruśa是无所不在的存在,因此除它之外,没有任何其他事物能够成为物质上的原因。 Prakrti并非无处不在,它被藏匿在Puruśa之中。 在 Puruśa 的主体中,Prakrti 只能在其获得 Puruśa 提供的机会时才能运作。 因此,在创造之科学中,仅有Puruśa作为行动主体,才是主要的有效因或工具因;而由于Prakrti在得到Puruśa赋予的权力后假扮行动主体,她便成为从属的有效因。 通过有效因在物质中产生的各种扭曲或表现,也就是我们所说的世间现象,是由Prakrti中的三个guńas [属性或束缚原则:萨特瓦、拉贾哈与塔玛。]所导致的。 这就解释了为何Prakrti会成为有效因与物质因之间的联系纽带。 因此,物体本身的坚固程度或脆弱程度完全取决于Prakrti的影响程度。

在所有领域中,Puruśa的作用都最为重要。 Prakrti仅能在Puruśa授权或允许其行事的范围内行事。 在进化过程中,Puruśa赋予Prakrti工作的权限,而后后者便开始工作。 微妙的Puruśa由于受到Prakrti中的三个guńas的束缚,逐渐变得粗糙。 在其最原始的状态下,Puruśa正缓慢而逐步地剥夺Prakrti此前所拥有的机会与自由;而由此变得原始化的Puruśa则逐渐恢复其精妙性,回归到其最终的本质状态。 在Prakrti的约束作用下,Puruśadeha [认知身体]的各种表现形式所呈现出的流动状态,就是我们所说的saiṋcara [从微妙到粗俗的外向性];而随着束缚逐渐松懈,最终导致Puruśadeha产生的逐步解放过程,则是我们所说的pratisaiṋcara [从粗俗到微妙的内向特质]。 现在已十分清楚,尽管Prakrti可以自由地正当使用其所获得的力量,但这种力量的获得与否却取决于Puruśa或Citishakti [认知原则],因此我们必须说,Prakrti不过是Puruśa本身、–、Shaktih以及Sá、Shivasya Shaktih的体现而已。

1-3. Tayoh siddhih saiṋcare pratisaiṋcare ca.

[Puruśa与Prakrti在saiṋcara (外向型动作)、pratisaiṋcara以及(这一充满争议的运动中得到了实现。]

大意:任何实体的存在都是通过其活动、思维或见证行为来被知晓的,其中见证行为属于Puruśa,而另外两个决定性因素则主要属于Prakrti;因此,只有当Prakrti完全与客观性融为一体时,人们才会认识到它才是这些行为与思维流程的因果实体。 Prakrti对客观性的这种占有取决于随着她日益增长 (saiṋcara)或-减少 (pratisaiṋcara)对Puruśa的影响。 Prakrti的体现存在于saiṋcara和pratisaiṋcara这两个过程中。 在 Prakrti 的所有这些表现形式中,Puruśa 不仅是物质上的原因,而且在所有状态与条件下都充当着见证者的角色。

1-4. Paramashivah Puruśottamah vishvasya kendram.

[位于宇宙核心的至高意识被称为Paramashiva或Puruśottama。]

大意:三价态的Prakrti显然正在通过其自身的结合力–来使原始的Puruśa变得粗糙,这是其活动过程中的一个环节。 她的另一种方法是逐渐减弱其三种属性对那个原始物体的影响,从而恢复Puruśa的特质,进而结束其束缚作用。 Prakrti中的第一个过程为离心过程,另一个为向心过程。 Brahma Cakra,或Srśt́i Cakra [宇宙循环],正是通过这些离心力与向心力的共同作用而显现出来的。 这个宇宙循环的核心确实就是Puruśa中的svabháva [特征轴承]。 整个Brahma Cakra的实质原因就是Puruśa或Shiva,我们将把这个核心称为Paramashiva或Puruśottama。

1-5. Pravrttimukhii saiṋcarah guńadháráyám.

[Saiṋcara (在宇宙循环之中)是在guńas (约束性原则)影响日益增强的作用下逐渐向外发展的。]

含义:在Prakrti的影响下,Puruśa从Brahma Cakra的核处向目标物体移动或表现出的现象,被称为pravrtti (外向阶段)。 由于 Prakrti 对其所见证的 Puruśottama 产生的初始影响,他内心便产生了存在感,在哲学语言中这被称为 Mahattattva [存在主义的 “我”];而促使这种 Mahattattva 产生的作用力,则被称为 Prakrti 的 sattvaguńa (有感知的原则)。 (Guńa has the meaning “绑定原则”。) Prakrti的运作力量所产生的第二种影响,便是催生出一种主体感或创造感。 这种Puruśa表达式的变化被称为Ahaḿtattva (执行者 “我”),而相关的作用力则被称为rajoguńa (变异原理)和Prakrti。 最终,由于Prakrti在连续攻击后所产生的更大作用力,Puruśa (主观宇宙最粗糙的客观对应物)便获得了最粗糙的客观性或完全的客观化。 Puruśa的这种状态被称为citta (思维内容)。 实现这种客观化的操作力量被称为tamoguńa (静态原理),亦即Prakrti。 也就是说,随着pravrtti [欲望与执着]的出现,saiṋcara的问题会直接从同一个Puruśa产生,并通过guńas的渐进过程不断发展。

1-6. Nivrttimukhii pratisaiṋcarah guńávakśayeńa.

[Pratisaiṋcara (在宇宙循环之中)是在guńas影响力逐渐减弱下的内敛式发展。]

含义:vrtti [渴望]的过剩量即为pravrtti [欲望的牵绊或加速的冲动]。 vrtti的衰退或减弱势头就是nivrtti [内向阶段中的超脱感或欲望的丧失]。 在离心运动过程中,在Prakrti的静态影响下,欲望在Puruśa中得到最充分的体现。 在Prakrti的静态影响下,出现在Puruśa内容中的citta实体,当被jiivátman [微观世界的个体灵魂或主观部分]视为可感知或可认知的事物时,便表现为五种粗大的物质元素、十种感官[器官]以及五种tanmátras [合理且极其合理的推断,或普遍的本质]。 当归因流程达到最终阶段时,guńas与–的脱落便开始了,也就是说,Puruśa会持续削弱Prakrti的力量。 其结果是,Prakrti在Puruśa的吸引下,被引向Puruśottama。 因此,这五种粗大的物质元素又会逐渐转化为该个体的身体、生命能量与心灵。 最终,随着束缚原则的消除,个体意识融合为Puruśottama。 正因为单位意识与其根本原因的融合,pratisaiṋcara的最终状态才是一种无属性的状态。 这可被称为个体生命的消解。

1-7. Drk Puruśah darshanaḿ Shaktishca.

[Puruśa是证明者,是最终的见证者;(行动能力)、Prakrti则是见证(以及那些被见证的事物)的行为。]

大意:表演即观看,见证便是drk [证据支持]。 由于后者缺失,所见便毫无依据。 思考、说话、行动、接受–,这些都属于行动的范畴。 为这些活动的存在及其实际影响提供证明的见证者是Puruśa,而在其见证之下开展的活动则带有guńas与Prakrti的属性。 如果我们将物质波的表现称为行动能力,那么其显而易见的见证者便是citta实体。 如果将 citta-ic 表达式称为行为能力,那么它的明显见证者便是 Ahaḿtattva (或是自我)。 如果将“自我”的表现或显现称为行为能力,那么其显而易见的见证者便是Mahattattva [“我”的特质感]。 如果我们把““我””的属性称为行动能力,那么它的见证属性,即““我知道我是””的属性,便可被视为最终极的见证。 这个“我所知道的”并非任何人物或事物的表面见证者,而是所有情况下一切事物的绝对见证者。 因此,坦白说,仅凭这一特征就属于drk [终极认知]的范畴。 这其实就是 Puruśa 所具有的意识。

1-8. Guńabandhanena guńábhivyaktih.

[随着guńas的束缚日益加剧,它们在各种基本因素的显现中充分展现了自己。]

含义:Guńa具有“约束原则”的含义。 对任何事物施加的束缚越强,它就会变得越粗糙。 当从Puruśa、Prakrti、绑定 Puruśa中获得自由之后,意识 Puruśa会在日益增强的束缚因素作用下蜕变为Mahattattva、Ahaḿtattva、citta等,而后在tamoguńa越来越强的束缚作用下,会依次形成粗劣态、气态、光态、液态以及(最终)的固态因素。 即便在后者之中,也存在不同程度的束缚。 由于束缚力的作用,原子间和分子间的距离不断减小,从而导致物质内部的摩擦力不断增大。 归因束缚的外部压力与内部摩擦迫使物体内部产生越来越多的归因表现。

此处需要记住,“属性表达式”并不意味着属性能力的过剩,而是指属性表现形式以及属性多样性的过剩。 ákáshatattva [超自然因素]具有传声属性。 假设我们将它的数值固定为100,那么当ákáshatattva因更强的静态束缚而转变为váyutattva [空中因素]时,触觉属性以及传声属性也会同时体现在其中。 但归因能力依然如故,–并未得到提升。 与ákáshatattva相比,váyutattva的传声性能有所下降,但声学属性与触觉属性的综合数值依然保持在100。

1-9. Guńádhikye jad́asphot́ah bhútasámyábhávát.

[由于guńas的压力过大,bhútas (五个基本因素)与lost、jad́asphot́a之间失去了适当的平衡,进而出现了(物质的爆炸)的情况。]

含义:即便物体本体已转化为kśititattva [固体因子],束缚原理的冲击依然持续不断,各要素的平衡就会被打破,进而出现jad́asphot́a [物质的爆炸]的情况。 由于这次爆炸,kśititattva因其内部摩擦过大而彻底或部分粉碎为更微小的元素,如ap [液体]、tejas [发光的]、marut [空中]和vyoma [空灵的]等因子,也就是说,它的运动经历了负向的saiṋcara过程。 尽管如此,爆炸后产生的那些更为微妙的元素自然又会沿着 saiṋcara 的老路前进。

随着 guńas 流动量的不断增大,宇宙意识中的那种超然元素也逐渐变得愈发粗糙,即从 ákásha,也就是维奥玛,到马鲁特,从马鲁特到特贾斯,从特贾斯到阿普,再从阿普到 kśiti。 这些变化进程越深入,物质实体中可见的属性差异就越是多样,同时它们的尺寸也会逐渐缩小。 尺寸收缩意味着内部摩擦的增加,而这种现象是由于外部归因流的过量或强度过大所导致的。 由于这些过度的内部摩擦,物质体会发生爆炸,并被粉碎成更微小的元素。 这些由过度归因压力引发的爆炸,仅发生在固体单元的应力程度相比其他单元异常过高时。 由于各元素之间的张力关系不存在巨大差异,(过高或过低),因此便形成了生命体,而非发生爆炸。

1-10. Guńaprabhávena bhútasaungharśádbalam.

[由于guńas的影响日益增强,各基本因素之间发生冲突,从而产生了bala (能量)。]

含义:作用在物体上的约束力越强,其内部摩擦力就越大。 这种力的冲突或相互作用被称为bala或práńa [动力或能量]。 这种práńa几乎存在于所有的物体或元素中,尽管它在这些物体或元素中的体现程度并不相同。

1-11. Dehakendrikáńi parińámabhútáńi baláni práńáh.

[在物理结构中形成核心并维持其整体性的内力,被称为práńáh (生命能量)。]

含义:如果由物体–内的外部与内部摩擦共同产生的合力–在该物体的某个部位找到了自己的核心,那么在该物体中起作用的各种力量或能量就统称为práńáh [生命能量]。

单词práńáh在梵语中以复数形式出现,因为它实际上代表十个váyus [体内的生命力量]。

1-12. Tiivrasaungharśeńa cúrńiibhútáni jad́áni cittáńu
mánasadhátuh vá.

[由于过度碰撞,一些原始物质被粉碎,从而产生了cittáńu (外质颗粒),也就是意识物质。]

大意:如果物体中的能量表现过于强烈,该原始实体的一部分会因物体内部的过度摩擦而被粉碎,并转化为cittáńu [思维内容],这种物质比以太更为微妙。 也就是说,心灵由物质产生。

1-13. Vyaśt́idehe cittáńusamaváyena cittabodhah.

[通过单元结构中胞质颗粒的结合,citta (客观的思维)的感受便逐渐形成。]

含义:位于各个物体内部、围绕其整体分布的所有cittáńus [外质颗粒]的协同整体,构成了该物体中citta的含义。 这个citta就是单元心智的已完成“I”,或者说目标“I”。 一个人的一切感知,无论是视觉上的还是听觉上的,都将保持不被察觉的状态,除非 citta 与他们对自己 的反思相认同。

1-14. Cittát guńávakśaye rajoguńaprábalye aham.

[随着guńas的影响逐渐减弱,rajoguńa开始占据主导地位,aham (行动力)便从citta中演化而来。]

大意:在Puruśottama [宇宙核心]的吸引作用下,心灵物质在vidyá shakti [内向的力量]的影响下逐渐向前移动,此时tamoguńa的主导地位逐渐减弱,而rajoguńa的影响力则日益显现。 在身心结构中,rajoguńa占主导地位的部分被称为ahaḿtattva [执行者 “我” 或所有者 “我”]。

1-15. Súkśmábhimukhinii gatirudaye ahaḿtattvánmahat.

[在进一步向微妙层面发展的过程中,mahat由ahaḿtattva演变而来。]

大意:在vidyá shakti的吸引作用下,rajoguńa对ahaḿtattva的影响也逐渐消失,这表明sattvaguńa已占据主导地位。 在 ahaḿtattva 中 sattvaguńa 占主导地位的那部分,被称为 mahattattva [纯粹的 “我” 的感受]。

1-16. Cittádahaḿprábalye buddhih.

[当 aham 大于 citta 时,buddhi (智力) 会发生变化。]

含义:如果 aham 的周长大于 citta 的周长,那么 citta 所对应的剩余部分就被称为 buddhi (智力)。

1-17. Ahaḿtattvát mahadprábalye bodhih.

[当 mahat 大于 aham 时,bodhi (直觉) 会发生变化。]

含义:如果 mahattattva 的尺寸大于 ahaḿtattva 的尺寸,那么 mahat 的多余部分就被称为 bodhi [直觉]。

1-18. Mahadahaḿvarjite anagrasare jiivadehe latágulme kevalaḿ
cittam.

[在那些尚未进化出aham和mahat的未发育完全的生物体中,也就是在藤本植物和灌木中,只有citta存在。]

大意:在未发育完全的生物、藤本植物及灌木中,可以发现仅有 citta 的表现出现,而 mahattattva 和 ahaḿtattva 的表现并未出现。

1-19. Mahadvarjite anagrasare jiivadehe latágulme cittayuktáham.

[在那些尚未进化出mahat的未发育完全的生物体中,也就是在藤本植物和灌木中,存在着aham以及citta。]

大意:在未发育完全的生物或藤本植物、灌木中,可能并未出现mahat的表现,而出现了aham和citta的表现。

1-20. Prágrasare jiive latágulme mánuśe mahadahaḿcittáni.

[在成熟的生物体中,无论是藤本植物和灌木,还是人类体内,都存在mahat、aham和citta。]

大意:在较为发达的生物体中,无论是藤本植物和灌木,还是人类,mahattattva、ahaḿtattva以及citta这三种都会显现出来。

1-21. Bhúmávyápte Mahati ahaḿ cittayorprańáshe
saguńásthitih savikalpasamádhih vá.

[当 aham 与 citta 合并为宏观的 Mahat 时,这一合并过程被称为 saguńásthiti 或萨维卡尔帕 samádhi。]

大意:在持续进行灵性修炼之后,mahattattva,也就是““我””的感受,会转变为宏观层面的““我””的感受,此时微观层面的citta会与aham融合,而aham则会与mahat融合。 当物体与其成因合为一体时,这种合并就被称为普拉拉亚或prańásha [彻底毁灭]。 由于宏观世界的citta由宏观世界 Aham衍生而来,而宏观世界 Aham则由宏观世界的Mahat衍生而来;当pratisaiṋcara处于内向运动状态时,[单元]与citta会合并为aham,aham则会合并为mahat,因此将其称为prańásha是完全合乎逻辑且合理的。 citta与aham的彻底毁灭状态,以及mahat的普遍存在状态,共同构成了saguńásthiti [超验状态],也就是所谓的savikalpa samádhi [全神贯注的出神状态]。

1-22. Átmani mahadprańáshe nirguńásthitih
nirvikalpasamádhih vá.

[当 mahat 与 Átman 合并时,它便被称为 nirguńásthiti (无对象状态),或称 nirvikalpa samádhi (心灵陷入难以确定的沉浸状态,或完全停止运转的状态)。].]

大意:当将“I”的那种感觉融入Citishakti [认知原则] –之中,而非在宏观的Mahat –中执行sádhaná以安装mahat时,mahat便处于完全沉浸的状态,这便是nirguńásthiti [一种无对象的状态],也就是涅槃状态samádhi [心灵陷入难以确定的沉浸状态,或完全停止运转的状态]。 由于不存在任何guńa,这种状态被称为nirguńásthiti,即无对象状态。 这种状态无法用言语表达,因为……

1-23. Tasyasthitih amánasikeśu.

[这个状态 (关于无分别的samádhi) 超出了心智的范畴。]

大意:这种超脱心灵范畴的虚无状态,是无法通过心灵来理解的。

1-24. Abhávottaránandapratyayálambaniirvrttih tasya pramáńam.

[这种空明状态之后所留下的持久愉悦,正是该状态的存在证明,也是让人对该状态产生坚定信念的依据。]

大意:在清醒状态下,心的三个阶段,即意识、潜意识与无意识,都处于活跃状态。 但由于更粗糙的条件更为活跃,那个更为微妙的条件便不那么显眼了。 在梦境中,粗糙的意识或清醒的意识处于休眠状态,而潜意识与无意识则保持活跃。 在睡眠期间,只有无意识的头脑保持活跃。 认为睡眠状态就是空虚状态的观点,经精细的哲学审视后是不可接受的,因为在此状态下,意识与潜意识的工作均由无意识心理来完成。 真正的空性状态,实则是心灵彻底毁灭的状态;因此,即便是有想定的samádhi也并非空性状态。 唯有无分别状态才是空性状态。 在这种绝对的空虚状态中,充斥着那个单一实体的那种令人振奋的精神波动,即便在那种空虚状态消失之后,也就是当心灵因未被满足的saḿskáras [过去行为所引发的相应反作用力矩]而回归之后,仍会持续流动并延续一段时间。 这些持续的兴奋与欢乐情绪不断提醒着“专注的”sádhaka [直觉型实践者],他或她的“无意识”状态曾是一种极致的幸福。

1-25. Bhávah bhávátiitayoh setuh Tárakabrahma.

[Nirguńa Brahma与Saguńa Brahma之间的桥梁被称为Táraka (解放) Brahma。]

含义:连接 Saguńa 的经验状态与 Nirguńa 的超经验状态的共同点被称为 Táraka Brahma。 Táraka Brahma 以 saguńa [体现为具体形态] 的形式出现,也就是 Mahásambhúti。

第2章

2-1. Anukúlavedaniiyaḿ sukham.

[一种愉悦的心理感受被称为幸福。]

含义:如果某人的saḿskára所对应的脑电波处于静止状态,而此时从任何普通物体或其他心灵实体中发出的脑电波与之相似,那么对于这个人而言,这些脑电波就被视为互补且相互对应的。 这些彼此共鸣的波动相互接触,便产生了所谓的幸福。

2-2. Sukhánuraktih paramá jaeviivrttih.

[对幸福的执着是生物生存的首要vrtti (倾向性)。]

大意:每一个生物都希望维持自己的生存,而这种自我保存的本能是一种心理能力。 幸福的缺失会危及一个人的存在感,因此人们不愿遭遇幸福的缺失;人们希望让幸福无处不在,将其作为唯一的庇护所。

2-3. Sukhamanantamánandam.

[无尽的幸福就是ánanda (幸福)。]

寓意:没有生物会满足于少得可怜的东西,更不用说人类了。 因此,微小的幸福无法满足任何人的需求。 人们渴望永恒的幸福。 这种无尽的幸福是一种超越福祸范畴的状态,因为借助感官所能感知到的幸福感,在达到无限状态时便超越了感官器官的局限。 这种无尽的幸福,就是所谓的ánanda [幸福]。

2-4. Ánandaḿ Brahma ityáhuh.

[这个ánanda被称为Brahma。]

主旨:那无限之物是唯一的,而非多个。 在无尽之中,多元性无从容身。 那个无比幸福的实体其实就是 Brahma,它是 Shiva 与 Shakti 的组合体。

2-5. Tasminnupalabdhe paramá trśńánivrttih.

[一旦获得(Brahma),所有的渴望都将得到永久的满足。]

主旨:生命体内心存在着对无限境界的渴望。 数量有限的物品是无法解渴的。 Brahma是唯一的无限存在,因此仅通过依托Brahma就能消除一切渴望与需求。

2-6. Brhadeśańáprańidhánaḿ ca dharmah.

[渴望并追逐伟大之人,便是dharma。]

大意:如此一来,无论有意还是无意,人类确实在追求无限。 当人们刻意追求伟大之物并为此祈祷时,其心态为称为 dharma,而所需付出的努力则为称为 dharma sádhaná [dharma的实践]。

2-7. Tasmáddharmah sadákáryah.

[因此,应当始终践行dharma。]

主旨:既然幸福是所有人的追求目标,而对幸福的渴望唯有在实现无限之后才能得到满足,而这种无限性的实现本身正是dharma sádhaná,因此然后 dharma sádhaná对每一个生物来说都是不可或缺的。 心智不成熟的人类低等生物无法完成dharma sádhaná。 但人类能够做到,而做不到的人根本不配被称为人类。

2-8. Viśaye puruśávabhásah jiivátmá.

[单位对象中Puruśa的反射被称为jiivátmá (个体灵魂)。]

大意:在灵性术语中,灵魂是唯一的。 无论心处于何种状态,是显现(例如,在有生命的生物和植物中)还是不显现(例如,在无生命的地球、铁等物质中。),Átmá都会持续不断地反思自身以及其对象——那些原始的对象–。 灵魂在心灵中的映像被称为jiivátmá,而此时的映照者-灵魂则被称为Paramátmá [至高灵魂]或Pratyagátmá。 (Pratiipaḿ vipariitaḿ aiṋcati vijánáti iti pratyak [“与某事物相对立并见证该事物的事物,即为直接认知”].),jiivátmá也可被称为ańucaetanya [微观意识]。 以同样的方式,我们也可以将Paramátmá称为Bhúmá Caetanya [宏观意识]。 所有微观世界的总和就是宏观世界。 从某种意义上说,这一说法是正确的,因为每一个心灵或原始实体都在以其自身的能力承载着至高之灵。 他们的集体能力其实就是宏观意识的能力。 Paramátmá是宏观意识的终极知晓者,而为什么 Paramátmá则被称为Bhúmá Caetanya。

2-9. Átmani sattásaḿsthitih.

[每个实体最终都会被嵌入到Átman中。]

含义:该实体在其citta的承载体中获得存在依据;citta的承载体则在于执行者“I”,或所有者“I”,也就是Ahaḿtattva;而执行者“I”,或所有者“I”的承载体,则体现为(即,在“我是”或Mahattattva)这一存在形式。 对……的知识 “我是” 实体,即。 “我知道我就是。” 在没有这种认知的情况下,–的实体意义 “我是” 或者 “我的存在” –仍处于危险之中,因其缺乏证据支持。 因此,一切事物的根源依然是“我知道”,紧接着的是“我是”。 这个“我”的“我知道”就是灵魂,因此所有实体的存在意义都依赖于Átman。

2-10. Otahprotah yogábhyáḿ saḿyuktah Puruśottamah.

[Puruśottama与每个实体分别关联,同时也与所有实体整体关联。]

大意:作为宇宙核心的Puruśottama,是每一个独立实体的见证者,也与它们有着直接的联系。 祂的这一关联被称为ota yoga [各个协会的yoga]。 显然,Puruśottama既是宇宙的统一体,也是集体意识的见证者。 他将自己与集体联系在一起的这种关系被称为prota yoga [普遍关联的yoga]。 换言之,可以说同时通过ota瑜伽和prota瑜伽与祂的客体相联的人就是Puruśottama。

2-11. Mánasátiite anavastháyáḿ jagadbiijam.

[宇宙的种子存在于心灵之外,处于心灵无法理解的状态之中。]

主旨:一切被创造出的物体都遵循因果法则。 在探寻 pratisaiṋcara 的作用机制时,我们找到了五个基本要素。 同样地,在探寻saiṋcara中的作用机制时,我们也得出了伟大的Mahat。 心灵除了 Mahat 之外没有其他存在之处,这种状态便是心灵的超心理状态。 在这种超心智状态中,心智已无法确定因果法则,因为进一步的探究会陷入无限倒退的谬误;也就是说,设想心智存在于其实际并不存在的状态之中,确实是一种谬误。 因此,关于创作究竟何时发生以及为何发生的疑问是多余的,也是站不住脚的。

2-12. Saguńát srśt́irutpattih.

[它的创造源自 Saguńa Brahma。]

大意:但由于被创造的世界与guńas相关,因此它确实是在Saguńa Brahma中演化而来的,而非在Nirguńa中。

2-13. Puruśadehe jagadábhásah.

[宇宙在认知体之中形成。]

主旨:世间一切有形与无形的事物,皆蕴含于Bráhmiidehe [宇宙天体]之中。 没有任何人或事物存在于Brahma之外。 “outsider”这个名称其实是个误称,–根本不存在。

2-14. Brahma Satyaḿ jagadapi satyamápekśikam.

[Brahma就是绝对真理;宇宙也是真理,但属于相对真理。]

含义:Brahma 就是 Satya [真理],也就是说它是不可改变的。 但我们不能说,在Prakrti以及时间、空间和主体这三项基本相对因素的影响下,Brahma的本体上所显现出的变化是虚假的,也不能说它们是永恒的真理。 我们只能说它们是相对真理,因为表面上的变化取决于时间、空间和人这三者之间的相对性。 作为独立实体或独立意识,其在发展过程中也与这三种因素相关,因此它的存在同样是一个相对的因素。 对一个相对存在的实体而言,另一个相对存在的实体似乎是一种精神真理;同样,对那个会变化的生命个体而言,这个多变的世界似乎也是一种真理。

2-15. Puruśah akartá phalasákśiibhútah bhávakendrasthitah
guńayantrákashca.

[Puruśa不采取任何行动,(直接地)也不行动,但它是各种行为与反应的见证者;位于Saguńa Brahma的核心位置,它是guńas的控制器。]

大意:Puruśa存在于所有实体的核心之中,这一观点既适用于个体也适用于集体。 这个集体核心中的Puruśa其实就是Puruśottama。 当“运作原理”的流动在物体内部产生能量时,这种能量的控制者便被称为kartá。 Puruśa无法控制这种能量,相反,位于guńas核心处的他,能够控制那些能量从中释放出来的非常 guńas。 因此,控制器Puruśa或Puruśottama不受guńas的管辖,而是其管理者或最高负责人。

2-16. Akartrii viśayasaḿyuktá buddhih mahadvá.

[buddhitattva或mahattattva本身并非执行者,但仍与各种对象相关联。]

含义:buddhitattva或mahattattva本身并不执行任何操作,但仍然与相关对象保持关联。

2-17. Ahaḿ kartá pratyakśaphalabhoktá.

[aham是行动者,直接享受或承受行动的后果。]

大意:ahaḿtattva才是真正的行为主宰与实施者,同时也是行为成果的享受者与承受者。

2-18. Karmaphalaḿ cittam.

[citta表现为行动的结果形式。]

大意:citta表现为行为的结果。

2-19. Vikrtacittasya púrvávasthápráptirphalabhogah.

[扭曲的citta恢复到原始状态的过程,就是体验行为所带来的结果——无论是快乐还是痛苦。]

含义:该动作具有将citta转化为另一种形态的含义。 如果我们将这种模拟转化的实现称为vikrti [扭曲],那么citta重新恢复到先前状态的过程则应被称为karmaphala bhoga [报应的体验 (快乐与痛苦)]。

2-20. Na svargo na rasátalah.

[没有天堂,也没有地狱。]

主旨:根本不存在天堂与地狱之类的事物。 当一个人行善并享受其带来的好处时,他周围的环境便被称为天堂;而当他作恶并承受其后果时,他周围的环境便成为他的地狱。

2-21. Bhúmácitte saiṋcaradháráyáḿ jad́ábhásah.

[在 saiṋcara 的流动中,物质在宇宙级的 citta 中形成形态。]

大意:ákáshatattva [vyomatattva,虚空因素]是在Prakrti的静态原理对宇宙中的citta产生更强烈影响的过程中演变而来的。 静性原理对ákáshatattva的影响产生了maruttattva [气态因素]。 如此,由马鲁特演化出了tejastattva [光亮因子],由特贾斯演化出了apatattva [液体因子],而kśititattva [固体因子]则由液体演化而来。 这些空灵的、气态的、发光的、液态的以及固态的因素被称为五种mahábhútas [基本要素],因为所有其他的都是bhútas [尸体] 或者,进化后的生物便是由这些元素孕育而成的。。

2-22. Bhútalakśańátmakaḿ bhútabáhitaḿ
bhútasaungharśaspandanaḿ tanmátram.

[Tanmátras (bhútas的微观微粒,或基本因子)代表bhútas,由bhútas携带,是由bhútas内部的碰撞产生的振动所形成的。]

含义:由内外压力所引发的物体内部的波动,会通过更微细的实体作为介质,以波的形式传递到单元体中各感官[器官]的不同通道。 这些波动从器官的那些通道出发,通过不同的神经或借助其内部分泌物,抵达大脑中的特定接收点。 此后,根据那些波动,模拟体citta [心理屏障]会呈现出外部物体的振动形态。 那些模拟性的、具有占有性的波动使citta与声音、触觉、形态、味觉或嗅觉等外部物体发生接触。 这类波被称为tanmátras [合理或过于合理的推断,或是普遍的本质]。

2-23. Bhútaḿ tanmátreńa pariciiyate.

[bhútas会通过其对应的tanmátras被识别。]

含义:一个物体所属的物理元素类别由其自身发出的tanmátra决定。 气态因素具有吸收或承载声音 tanmátra的能力,固态因素具有吸收或承载声音与触摸 tanmátra的能力,光态因素具有吸收或承载声音、触觉与表格 tanmátras的能力,而液态因素则具有吸收或承载声音、触觉、形态与味道 tanmátras的能力。 实体因子具有吸收或承载全部五种tanmátras的能力:声音、触觉、形态、味道和气味。

为了确定一个物体所属的物理元素类别,我们必须以该物体所具有的最基础的tanmátras作为判断依据。 五种感官器官–,即眼睛、耳朵、鼻子、舌头和皮肤–,的功能是接收来自外部物体或环境的信号tanmátras。 运动器官–,即声带、双手、双腿、肛门以及生殖器官–,其功能是在saḿjiṋá [内在感知]的辅助下将内在的tanmátras传递到外部;而práńendriya [生命力]的功能则是将客观事物与心灵物质相结合,并在citta中产生轻、重、暖或冷的感觉。

2-24. Dvárah nád́iirasah piit́hátmakáni indriyáńi.

[感官(器官)是由器官的通道、神经、神经液以及器官(在大脑中)的相应调节机制piit́has (座位)共同构成的。]

含义:器官(也就是说,tanmátras首先将客观性带入生物体的门户之中)的门户、对tanmátras的波动产生反应的神经纤维、因tanmátrik的振动而震动的神经分泌物,以及神经细胞上tanmátrik的波动与citta相连接的部位,这些共同被称为indriyas [器官]。 也就是说,我们通常所说的眼睛内部处于活跃状态的光神经、视液以及神经细胞的视点,共同被称为眼睛 indriya。

第3章

3-1. Paiṋcakośátmiká jaeviisattá kadaliipuśpavat.

[生物是由五个kośas (心灵的层次)构成的复合体,就如同芭蕉花由(带着它的花瓣)构成一样。]

大意:在pratisaiṋcara中,随着citta的出现,心智的普遍显现也逐渐随之出现。 在这股显现的流动之中,我们在整体结构中发现最粗糙的鞘或细胞是kámamaya kośa [意识思维],比这更微妙的是manomaya kośa [潜意识],比这更微妙的是潜意识atimánasa kośa [超意识心智],比这更微妙的是超心智vijiṋánamaya kośa [潜意识心灵],而最为微妙的是kośas,即hirańyamaya kośa [微妙的因果心智]。 该装置的原始容器为安纳玛雅 kośa [肉体],它属于 saiṋcara 的财产。 kámamaya和摩诺玛雅 kośas分别被称为粗略心与微妙心,而其余的三 kośas,也就是atimánasa、vijiṋánamaya和hirańyamaya,则被统称为因果[或星体心,或无意识心]。 粗浅心智的见证 puruśa 被称为 Prájiṋa,微妙心智的见证被称为 Taejasa,而无意识心智的见证则被称为 Vishva。 Saiṋcara的annamaya,即kośa——那个作为生命实体的粗陋容器——被称为sthula deha [粗陋之身]。 从kámamaya到hirańyamaya的这五个kośas被称为sukśma deha [微妙的躯体],而mahattattva和ahaḿtattva则被称为sámánya与[超因体,即位于hirańyamaya kośa与(直至合并为止) Puruśottama之间的体]。 与车前草的花一样,对于这些kośas而言,也只有去除其粗糙的部分后,才能观察到并理解那些微妙之处。

3-2. Saptalokátmakaḿ Brahmamanah.

[宇宙意识是由七个世界 (层次,世界) 组合而成的。]

大意:宇宙意识存在于七个界中,即[世界]、bhú [物质世界]、bhuvah [粗略的精神世界]、svah [微妙的精神世界]、mahah [超心智世界]、janah [潜意识世界]、tapah以及Satya。 Puruśottama,作为宇宙中的Mahattattva与Ahaḿtattva的见证者,被称为萨蒂亚洛卡。 他亦被称为因果宇宙体。 puruśa (知晓者)的认知功能,即Brahma的hirańyamaya kośa [因果宇宙意识]中的认知层面,被称为Virát́a或Vaeshvánara,而与之相关的loka则被称为塔帕洛卡。 puruśa对Brahma的vijiṋánamaya kośa [潜意识的宇宙意识]的见证也被称为Virát́a或Vaeshvánara,而相关的loka则被称为janarloka。 puruśa对Brahma的atimánasa kośa [超心智的宇宙意识]的见证也被称为Virát́a或Vaeshvánara,而相关的loka则被称为摩诃罗卡。 这三个kośas的统称是“因果宇宙意识”,或是“微妙宇宙躯体”。 Brahma中的曼诺玛雅kośa被称为微妙的宇宙心,而它所见证的puruśa则被称为Hirańyagarbha。 这也属于微妙宇宙体的范畴,而相关的loka被称为斯瓦尔洛卡。 Brahma中的kámamaya kośa被称为原始宇宙意识,而它所感知到的puruśa则被称为Iishvara。 这也可被称为原始宇宙天体。 根据其表达的微妙程度或粗糙程度,这个kośa被称为部分bhuvah。 [粗糙的精神世界],以及部分 bhúrloka [原始的物理世界]。

3-3. Kárańamanasi diirghanidrá marańam.

[在因果心中的长眠即是死亡。]

大意:在清醒状态下,意识、潜意识与无意识这三种心智始终处于活跃状态。 在梦中,只有粗略意识或清醒意识处于睡眠状态,而另外两种意识则保持活跃。 在睡眠状态下,意识与潜意识都处于静止状态;只有无意识保持清醒,承担着另外两种意识的工作。 当心理与生理的对应关系中出现振动差异时,潜意识也会变得不活跃。 这种状态被称为死亡。

3-4. Manovikrtih vipákápekśitá saḿskárah.

[正在等待表达的思维物质的扭曲形态 (也就是说,一种潜在的反应。) 被称为 saḿskára。]

大意:无论行为是善是恶,都会引发某种心理扭曲。 然而,心灵通过vipáka恢复了正常的平静,也就是说,在经历了自身善行或恶行的后果之后。 发生过行动的地方, 但其后果尚未被审议或执行,也就是说,vipáka被暂时搁置,这种被暂停的状态下的延期的 vipáka被称为saḿskára [潜在的反应]。

根据死亡时刻存于因果心或潜意识中的saḿskáras的属性,Prakrti为通过vipáka获得那些 saḿskáras,促使无形的意识与有生命的结构产生接触(1) 在各种生物的子宫中,存在着与那些无形的意识所产生的、由saḿskára-determined的心理波动具有相似性的生命结构–。 我们将其称为相关单元的重生。 人死后通常会带着 saḿskáras 离开,这取决于其生前的行为表现。

3-5. Videhiimánase na kartrtvaḿ na sukháni na duhkháni.

[在无形的意识中,没有行为主体,也没有快乐或痛苦的感觉。]

大意:当心灵与身体分离,也就是死亡之后,那个整体中便不可能存在幸福或痛苦的感觉,因为要感知快乐与痛苦,就需要脑神经细胞以及部分神经纤维(那些无形的灵魂在死后便不再拥有。);因此,那些认为某人的无形灵魂会因某种行为而幸福或痛苦,或会满足其报复心理的流行教条与信念,完全是错误的。

3-6. Abhibhávanát cittáńusrśt́apretadarshanam.

[鬼魂的景象是由高度集中的思维中的cittáńu (思维内容)所形成的。]

大意:其实,鬼魂是不存在的。 当人处于恐惧、愤怒或催眠状态时,若能暂时集中注意力,其心灵物质便会呈现为所想象的对象形态。 在这种状态下,人也能看到自己思想的景象。 独自思考鬼魂与灵体时,他或她会在户外也看到它们。 对内在思维的外在感知可被称为正性幻觉。 相反,在这种心态下,即便是真实存在的物体也可能显得不存在。 这可以称之为负面幻觉。 那些说自己见过鬼的人没有说谎。 在他们看来,只有心灵的错觉才表现为视觉感知。

如果催眠状态极其深入,人就可能会将自己的本体误认为是灵魂或鬼魂。 遇到这种情况时,那个人的举止会让人们开始说某某人被鬼附身了。 神狂症或神显性附身也属于同一类。

3-7. Hitaeśańápreśito’pavargah.

[对某一行为的回报,是由对福祉的(神圣的)渴望所指引的。]

大意:即便在(某项行为完成后结出的果实)这一行为的回报背后,也蕴含着神圣的仁慈之心。 对恶行的惩罚能让人学会远离恶事。 善行与仁慈行为所带来的回报告诉人们,如果他们做出恶行,就永远无法获得这样的回报。

3-8. Muktyákáunkśayá sadgurupráptih.

[出于对mukti (解放)的强烈渴望,人们便能获得自己的圣师(完美的大师)。]

大意:当一个人心中萌生强烈的解脱渴望时,他或她便能凭借这份渴望找到自己的萨德古鲁,即[真正的精神导师]。

3-9. Brahmaeva gururekah náparah.

[只有Brahma才是大师,没有其他人。]

大意:Brahma本身就是大师。 Brahma独自通过不同的载体或媒介,指引各个单元走向解放之路。 除了Brahma之外,没有人能理解“guru”这个词的真正含义。

3-10. Bádhá sá yuśamáná shaktih sevyaḿ sthápayati lakśye.

[障碍正是帮助人达成目标的助力。]

寓意:实际上,障碍在sádhaná [灵修修行]的道路上并非敌人,而是朋友。 他们只为一人提供服务。 正因有这些障碍,与他们的战斗才会如此激烈,而正是这种反制努力让sádhaka [追求精神境界的人]得以实现其珍视的目标。

3-11. Prárthanárcaná mátraeva bhramamúlam.

[祈祷与仪式性崇拜 [[只不过是]]一种令人困惑的来源。]

大意:向神祈求某物是毫无用的,因为他必定会赐予所需之物。 以崇拜的名义进行恳求或纠缠,不过是阿谀奉承罢了。

3-12. Bhaktirbhagavadbhávaná na stutirnárcaná.

[虔诚是对上帝的思索,而非对上帝的谄媚或仪式性的崇拜。]

主旨:始终将心神融入对上帝的思念之中,便是虔诚。 虔诚与诵念圣歌或使用各种仪式用品进行崇拜无关。 信徒可以践行这些行为,但它们并非虔诚修行sádhaná中不可或缺的部分。

4-1. Triguńátmiká srśt́imátrká asheśatrikońadhárá.

[三属性原始力量(万物的创造者)以无尽的三角形形态持续流动。]

大意:在至高无上的Puruśa中,萨特瓦[有感知能力的]、拉贾哈[变异的]与塔玛哈[静态的]这三种能量流中存在着无数个线性波动。 它们的三重属性流会不断演变为三角形或其他不同的多锥形或多边形图形。 由于svarúpa parińáma [同态演化]的存在,就连这些多边形图表也在逐渐变为三角形。 这个三重属性的mátrkáshakti [原始力量]是无穷无尽的。

4-2. Tribhúje Sá svarúpaparińámátmiká.

[在力量三角中,Prakrti的三个属性处于不断相互转化的状态。]

大意:在这些三角形中,萨特瓦不断转化为拉贾,拉贾又转化为塔玛,塔玛再转化为拉贾,拉贾最终又转化为萨特瓦,这样的循环往复永无止境。 这些变换被称为svarúpa parińáma [同态演化]。

4-3. Prathamá avyakte Sá Shivánii kendre ca Paramashivah.

[在第一阶段(尚未进入实际显现的阶段)中,Prakrti被称为Shivánii,而位于核心处的见证者Puruśa则被称为Paramashiva。]

大意:连接这些三角形中点的线段所对应的标识为Puruśottama,或Paramashiva。 只要这些三角形在受力作用下不会失去平衡,我们就可以将其视为三角形容器的初始阶段。 这一初始阶段确实属于进化前的阶段,因此纯粹是一个理论阶段。 Prakrti,即这些初始容器的创造者,被称为Shivánii或Kaośikii,而负责见证的Puruśa则被称为Shiva。

4-4. Dvitiiyá sakale prathamodgame Bhaeravii Bhaeraváshritá.

[在第二阶段,当进化的萌芽出现时,Prakrti被称为Bhaeravii,而作为见证者的Puruśa则被称为Bhaerava。]

含义:当三角形的平衡状态被打破时,进化的萌芽会从任意一个顶点产生,并根据guńas的度数沿直线向前发展。 这种状态其实就是 Puruśa 和 Prakrti 的显现状态。 此处,Puruśa其实就是saguńa [合格的],而Prakrti则有机会表达自己。 Prakrti,此状态的创造者名为Bhaeravii;shakti,而见证者的名字为Bhaerava;Puruśa。

4-5. Sadrshaparińámena Bhavánii Sá Bhavadárá.

[在振动世界中,存在着一系列曲率相似的序列 (同质性)。 此处,Prakrti被称作Bhavánii,而作为见证的Puruśa则被称作Bhava。]

大意:随着时间推移,由于内部冲突,力的流动会出现一些弯曲,同时 Puruśabháva [意识立场] 的密度也会持续下降。 正是在这种条件下,第一个kalá [曲率]诞生了。 第二个kalá与第一个(并不完全相同)相似,第三个与第二个相似,以此类推。 kalá praváha [连续或阶段性流程]就是如此。 kalás的这种依次演变被称为sadrsha parińáma [同质性,或相似性]。 在这些同质化波动中,精神世界与物质世界得以形成。 正是由于这种(同形物)式的曲线演化,我们才会发现人类的后代仍是人类,树木的种子也会长成树木。 kalás彼此相似但并不完全相同,因此尽管两个接连的 kalás之间的差异难以察觉,但彼此关联较远的kalás之间的差异则清晰可见。 尽管我们每天所见之人的身体变化难以理解,但若二十年后看到一个五岁的孩子变成了二十五岁的青年,我们肯定能够分辨出其中的差别。 尽管人类由人类繁衍而来,但百万年前的人类与今天的人类之间仍存在巨大的差异。 事实上,这个显现世界的主宰就是这股有序的力量,它被称为Bhavánii shakti,而对其见证的存在Puruśa其实就是Bhava。 bhava这个词有“创造”的含义。

4-6. Shambhúliuṋgát tasya vyaktih.

[创作过程始于Shambhúliuṋga。]

大意:实际上,从理论阶段向实际应用的转变,始于 Bhavánii 首次从三角形容器的某个点中显现出来之时。 理论与实践演变的共同点被称为Shambhúliuṋga [在三角形的顶点处有Puruśa,它是saiṋcara的来源。]。 实际上,这个Shambhúliuṋga就是根本积极性的起点,其后是náda [毫无弯曲的流畅流动],再接着是kalá。

4-7. Sthúliibhavane nidritá sá kuńd́alinii.

[在最原始的状态下,潜伏在Svayambhúliuṋga之中的paráshakti被称为kuńd́alinii (“盘绕的蛇形物”)。]

含义:最后一个表达点,即 Bhavánii shakti 的边缘部分,代表了力量 – 的最终表达状态,也是最原始的状态。 在这种原始状态下,处于静止状态的paráshakti [一种内向的、无处不在的力量]与jiivabháva [有限的主观性]一同被称为kulakuńd́alinii [“盘绕的蛇形物”, 或根本性的负面力量]。

4-8. Kuńd́alinii sá múliibhútá rńátmiká.

[kuńd́alinii就是(力量)的本质负面性。]

主旨:显现的终极境界被称为Svayambhúliuṋga。 Svayambhúliuṋga是负性的终极所在,kulakuńd́alinii的力量就蕴藏其中,它静止不动,如同蛇一般盘绕着。 如果 Shambhúliuṋga 是根本的正性,那么位于 Svayambhúliuṋga 处的 kulakuńd́alinii,我们可以称之为根本的负性力量。

第五章

5-1. Varńapradhánatá cakradháráyám.

[在社会循环的运转中,总有一个阶级处于主导地位。]

大意:由于远古时期尚未形成完善的社会秩序,我们可以将那个时代称为Shúdra时代;在那个时代,所有人皆依靠体力劳动生存。 随后便是族长 – 的时代,也是强者与勇士 – 的时代,我们亦可将其称为 Kśatriya 时代。 随后便是知识分子时代,我们可将其称为Vipra时代。 终于迎来了资本家时代,即Vaeshya时代。

在Vaeshya时代,由于剥削,战士与知识分子沦落到体力劳动者的地步,于是shúdra革命爆发了。 shúdras既没有健全的社会秩序,也没有足够的智慧来治理社会。 因此,后资本主义的治理权便落入了在shúdra革命中发挥领导作用的人手中。 这些人勇敢无畏,因此开启了第二个Kśatriya时代。

如此,Shúdra、Kśatriya、Vipra和Vaeshya这四个阶段便依次更替,随后发生变革;接着第二个循环顺序便开始。 因此,samája cakra [社会循环]的旋转仍在继续。

5-2. Cakrakendre sadvipráh cakraniyantrakáh.

[位于社会循环的核心,萨德维普拉斯掌控着社会循环。]

大意:那些坚定的道德主义者与真诚的灵性主义者,那些希望通过武力手段终结不道德行为与剥削的人,被称为萨德维普拉斯。 他们不属于社会循环的边缘,因为他们将牢牢立足于社会循环的核心,从而掌控社会。

社会循环无疑会不断循环。 但是,如果由于他们的优势地位,Kśatriya时代的武士、Vipra时代的知识分子或Vaeshya时代的资本家蜕变为贪婪的剥削者,而非履行仁慈管理者的职责,那么圣贤们的神圣职责便是保护正义之人和受压迫者,通过武力镇压恶人和剥削者。

5-3. Shaktisampátena cakragativardhanaḿ krántih.

[通过施加力量来加速社会循环的变动,被称为“进化”。]

大意:当武士们堕落为剥削者时,圣贤们将通过征服这些剥削武士来建立Vipra时代。 因此,本应通过自然进程到来的Vipra时代,因外力干预而得以加速到来。 以这种方式发生的年龄变化可被称为kránti [“进化”]。 进化与svábhávika parivarttana [自然变化]之间的区别仅在于:在进化中,社会循环的运转是通过施加力量来加速的。

5-4. Tiivrashaktisampátena gativardhanaḿ viplavah.

[通过施加巨大力量来加速社会循环的变动,被称为“革命”。]

含义:当某个时代在短时间内被后续时代所取代,或者需要施加巨大的力量才能打破该时代的根深蒂固的霸权时,这种变革便被称为viplava [“革命”]。

5-5. Shaktisampátena vipariitadháráyáḿ vikrántih.

[通过强行手段扭转社会循环的运行方向,被称为“逆向进化”。]

含义:如果通过强制手段使某个年龄阶段倒退至之前的阶段,这种变化就被称为vikránti [“counter-evolution”]。 例如,在Vipra时代之后出现Kśatriya时代,这就是逆向进化。 这种逆向进化极其短暂。 也就是说,在极短的时间内,这个时代又会再次被下一个时代或再下一个时代所取代。 换句话说,如果通过逆向进化,Kśatriya时代突然超越了Vipra时代,那么Kśatriya时代也不会持续太久。 不久之后,要么是Vipra年龄到来,要么作为其自然结果,Vaeshya年龄也会出现。

5-6. Tiivrashaktisampátena vipariitadháráyaḿ prativiplavah.

[通过施加巨大力量来扭转社会循环的走向,被称为“反革命”。]

大意:同样地,如果在极短的时间内,通过巨大的力量使社会循环倒转,这种变化就被称为prativiplava [“反革命”]。 反革命比反进化更为短暂。

5-7. Púrńávartanena parikrántih.

[社会循环的一次完整旋转被称为“边缘演化”。]

含义:社会循环完成一次完整旋转,以shúdra的革命作为终结,这一过程被称为parikránti [“外围演化”]。

5-8. Vaecitryaḿ prákrtadharmah samánaḿ na bhaviśyati.

[多样性,而非同一性,才是自然法则。]

主旨:多样性,而非同一性,才是最高运作原则的固有特征。 宇宙中不存在两个完全相同的物体,无论是两个天体、两个心灵、两个分子还是两个原子。 这种多样性是最高运作原则的固有趋势。

那些想要让一切变得平等的人必定会失败,因为他们违背了最高运行法则的固有特性。 在至高法则的未显现状态中,万物才是平等的。 那些想要让一切平等的人,必然会想到毁灭一切。

5-9. Yugasya sarvanimnaprayojanaḿ sarveśáḿ vidheyam.

[每个人都应享有达到某一年龄的最低要求保障。]

Purport: Hararme pitá Gaorii mátá svadeshah bhuvanatrayam. 也就是说,“至高意识是我的父亲,至高运行法则是我的母亲,而三界则是我的故乡。”宇宙中的所有财富都是众人的共同财产,尽管宇宙中没有任何两样东西是完全相同的。 因此,生活的基本需求应当为每个人所享有。 换言之,必须为所有人提供食物、衣物、医疗、住房和教育。 然而,人类的最低需求会随着时代的变迁而改变。 例如,在某个时代,最基本的交通工具可能是自行车,而在另一个时代则可能是飞机。 必须根据每个人的年龄为其提供最低限度的生活保障。

5-10. Atiriktaḿ pradátavyaḿ guńánupátena.

[多余的财富应当根据有功之人的功绩大小,分配给他们。]

大意:在满足所有年龄段人群的最低需求之后,剩余的财富需根据有功之人的功绩大小进行分配。 在自行车已是普通人最低配置的时代,医生则必须拥有机动车。 为表彰人们的功绩,并为有功之士提供更多服务社会的机会,必须为他们配备机动车。 那句“量力而行,按需而取”的话听起来很美好,但在现实世界的艰难环境中却毫无作用。(1)

5-11. Sarvanimnamánavardhanaḿ samájajiivalakśańam.

[提高人民的最基本生活标准,是社会充满活力的体现。]

主旨:有德之人应获得超过普通人最低标准的那部分待遇,同时也应不断努力提高最低生活标准。 例如,如今普通人需要自行车,而有功之士需要机动车,但应当努力为普通人提供机动车。 在为每个人配备机动车之后,或许还有必要为每位有功之士提供一架飞机。 在为每一位有功之士提供飞机之后,还应努力为每一位普通人提供飞机,从而提高最低生活标准。 这样一来,提升最低生活标准的努力就不得不永无止境地继续下去,而人类的日常发展与繁荣也取决于这一努力。

5-12. Samájádeshena viná dhanasaiṋcayah akartavyah.(2)

[未经集体机构的明确许可或批准,任何个人都不应被允许积累任何物质财富。]

主旨:宇宙是所有人的共同财产。 所有人均享有使用权,但任何人都没有权利滥用这一集体财产。 如果一个人获取并积累了过多的财富,他或她就会直接减少社会中其他人的幸福与便利。 这种行为是公然的反社会行为。 因此,任何人都不应未经社会许可便积累财富。

5-13. Sthúlasúkśmakárańeśu caramopayogah prakartavyah
vicárasamarthitaḿ vańt́anaiṋca.

[宇宙中的一切世俗、超世俗以及精神层面的潜能都应得到最大程度的利用与合理分配。]

主旨:应在粗略世界、微妙世界以及因果世界中发掘现有的财富与资源,以造福所有人。 隐藏在quinquelemental世界、–的固态、液态、发光态、气态以及–中的所有资源都应被充分利用,而努力做到这一点将确保宇宙得到最大程度的发展。 人们必须认真探索陆地、海洋和太空,以寻找、开采并加工满足自身需求所需的原材料。

人类积累的财富应当得到合理分配。 换言之,必须为所有人保障最低限度的需求。 此外,还需考虑到优秀人才的需求,某些情况下还需考虑有特殊需求的人士的需求。

5-14.
Vyaśt́isamaśt́isháriiramánasádhyátmikasambhávanáyáḿ
caramo’payogashca.

[应当最大限度地发挥人类社会个体与集体在物质、形而上学及精神层面的潜能。]

主旨:社会必须确保集体身体、集体意识与集体精神得到最大程度的发展。 人们绝不能忘记,集体福利源于个体,而个体福利则依赖于集体。 如果不通过妥善提供食物、光线、空气、住所和医疗救治来保障每个人的舒适生活,就永远无法实现整个群体的福祉。 必须以促进集体福利的精神来推动个人福利的提升。

若不培养正确的社会意识、不鼓励服务社会的精神、不唤醒每个个体的知识觉醒,集体意识的发展便无从实现。 因此,出于对集体心智福祉的考量,人们必须促进个体心智的幸福。

个体缺乏精神道德与灵性,将会动摇集体的根基。 因此,为了集体利益,就必须唤醒个体的灵性。 仅有少数坚强勇敢的人、少量学者或几名灵修者存在,并不能说明整个社会的进步。 每个人身上都蕴含着无限发展身体、心智与精神潜能的潜力。 这种潜力必须被充分利用并转化为现实。

5-15. Sthúlasúkśma kárańo’payogáh susantulitáh vidheyáh.

[这些物质、形而上学、世俗、超世俗以及精神层面的应用之间应当有恰当的平衡。]

主旨:在促进个人与集体福祉的同时,应当对物质、精神与心灵层面,以及粗略、微妙与因果世界之间进行恰当的调整。 例如,社会有责任满足每个人的基本需求,但若社会出于这一责任而为所有人提供食物和住房,个人的主动性就会受到抑制。 人们会逐渐变得无精打采。 因此,社会必须作出安排,让人们能够根据自身的能力付出劳动,从而获得购买基本生活所需物品所需的资金。 为了提高人们的基本生活标准,最好的办法就是提升他们的购买力。

“恰当的调整”也意味着,在寻求那些在身体、心智及精神层面都较为成熟的人的服务时,社会应当采取平衡的政策。 社会会根据一个人在身体、智力或精神方面的哪方面能力最为突出,来要求其提供相应的服务。 对于那些身体与智力都足够发达的人,社会会采取平衡的政策,相应地更多需求智力服务而非体力服务,因为智力相对更为精微且稀缺。 从那些在身体、心智和精神层面都得到发展的人身上,社会会获得最大的精神层面的服务,较少的智力层面的服务,以及更少的身体层面的服务。

就社会福利而言,拥有精神力量的人能够提供最大的帮助,其次是拥有智力力量的人。 那些拥有体力的人,尽管力量不可小觑,却无法独自完成任何事情。 无论他们做什么,都是按照那些拥有智慧与精神力量之人的指示来做的。 因此,控制社会的责任不应掌握在仅有体力的人手中,也不应掌握在仅有勇气的人手中,更不应掌握在仅有智力发展的人手中,或是仅拥有世俗知识的人手中。 社会控制必须掌握在那些同时具备高尚品德、智慧与勇气的人手中。

5-16. Deshakálapátraeh upayogáh parivarttante te upayogáh
pragatishiiláh bhaveyuh.

[利用方法应随着时间、地点和人的变化而改变,且这种利用应当是逐步发展的。]

主旨:任何物品的正确使用方式都会随着时间、地点和使用者的变化而改变。 那些无法理解这一简单原则的人想要固守过去的旧框架,结果便被现代社会所排斥。 基于狭隘的民族主义、地域主义、宗族自豪感等的情感,往往会使人远离这一基本原则,因而他们无法毫无保留地将其视为不容置疑的真理。 因此,在给自己的国家、同胞以及自身造成难以形容的破坏之后,他们不得不偷偷躲到幕后去。

每个物品的利用方式会随着时间、地点和人的不同而改变。 这一事实必须被接受,认识到这一点之后,人们就必须逐步运用每一件物品与每一个想法。 例如,有权势的人用来操作巨大锤子的能量,本应通过科学研究用来同时操作多把锤子,而不应白白浪费在操作一把锤子上。 换言之,以进步思想为指引的科学研究,应当从相同的人类潜能中挖掘出越来越多的价值。 在科学高度发达的时代仍使用过时的技术,并不能视为进步的标志。

社会必须勇敢地面对因进步思想与发达技术所创造的各种资源与材料的使用而可能出现的各种障碍,无论其规模大小。 通过奋斗,社会必须沿着实现人生全面发展的道路向前迈进,走向胜利。

Pragatishiila upayogatattvamidaḿ sarvajanahitárthaḿ sarvajanasukhárthaḿ pracáritam. [这就是渐进利用理论,其宗旨是为所有人的幸福与全面福祉而服务。]

逐字翻译 Sútra

第1章

1-1 Shivashaktyátmakaḿ Brahma。

Shiva = Puruśa,即宇宙意识,从字面意义上讲就是“万物皆存于其中”;Shakti = Prakrti,即宇宙运作原理,从字面意义上讲就是“创造事物的能力”;átmakaḿ为多种要素的复合体;Brahma即至高存在,(来自brhat,意为“伟大”)

[Brahma是Shiva与Shakti的复合体。]

1-2 沙克蒂,Sá,湿婆之沙克蒂。

Shaktih = 运行原理,宇宙力量,Prakrti;Sá = 她,Prakrti;Shivasya (第6种情况) = 属于 Shiva

[Shakti (操作原理)就是Shiva的shakti (力量)。]

1-3 Tayoh siddhih saiṋcare pratisaiṋcare ca.

tayoh (第6种情况) = 两者之中;siddhih = 证明,实现;saiṋcare (第7种情况) = 存在于saiṋcara之中。saiṋcara = 从字面意义上讲就是“恰当的运动”,即从微妙到粗糙的创造过程中的外向阶段:sam (专有名词) – car (离开) + ghaiṋ (后缀)。pratisaiṋcare (第7种情况) = 存在于从粗糙到微妙的创造过程中的内向阶段:prati = 反向,相反;ca = 和

[Puruśa与Prakrti在saiṋcara (外向型动作)、pratisaiṋcara以及(这一充满争议的运动中得到了实现。]

1-4 帕拉马希瓦即 Puruśottamah,是万物的中心。

Parama = 至高无上;Shivah = 意识;Puruśottamah = 从字面意义上讲即“最高意识”,是创世核心中的宇宙意识的名称;vishvasya (第6种情况) = 宇宙的;kendram = 核心

[位于宇宙核心的至高意识被称为Paramashiva或Puruśottama。]

1-5 Pravrttimukhii saiṋcarah guńadháráyám。

pravrtti = 欲望,向粗糙状态的转变;mukhii = 朝向;saiṋcarah = “正确的运动”;guńa = 约束原则、属性、特质;dháráyám (第7种情况) = 处于流动之中

[Saiṋcara (在宇宙循环之中)是在guńas (约束性原则)影响日益增强的作用下逐渐向外发展的。]

1-6 Nivrttimukhii pratisaiṋcarah guńávakśayeńa。

nivrttimukhii = 向欲望减弱的运动:ni (缺乏) – vrtti (渴望) + mukhii (朝向);pratisaiṋcarah = 向宇宙核心的向心运动;guńa = 约束原则;avakśayeńa (第三种情况) = 通过逐渐减弱的方式

[Pratisaiṋcara (在宇宙循环之中)是在guńas影响力逐渐减弱下的内敛式发展。]

1-7 Drk Puruśah darshanaḿ Shaktishca.

drk = 目击者;Puruśa = 宇宙意识;darshanaḿ = 观看的行为;Shaktishca = 以及 Shakti

[Puruśa是证明者,是最终的见证者;(行动能力)、Prakrti则是见证(以及那些被见证的事物)的行为。]

1-8 Guńabandhanena guńábhivyaktih。

guńa = 约束原则;bandhanena (第三种情况) = 通过约束或束缚;guńa = 质量;abhi = 完好无缺的;vyaktih = 表达,显现

[随着guńas的束缚日益加剧,它们在各种基本因素的显现中充分展现了自己。]

1-9 Guńádhikye jad́asphot́ah bhútasámyábhávát。

guńa = 约束,束缚性原则;adhikye (第7种情况) = 过度;jad́a = 固有因素,原始的物理性;sphot́a = 因外部压力过大而爆裂;bhúta = 从字面意义上讲就是“被创造出的物体”,属于五大基本因素之一;sámya = 平衡;abhávát (第5种情况) = 源于缺失

[由于guńas的压力过大,bhútas (五个基本因素)与lost、jad́asphot́a之间失去了适当的平衡,进而出现了(物质的爆炸)的情况。]

1-10 Guńaprabhávena bhútasaungharśádbalam。

guńa = 约束原则;prabhávena (第三种情况) = 通过影响的方式;bhúta = 被创造出的对象,基本要素;saungharśát (第5种情况) = 由冲突产生;balam = 能量

[由于guńas的影响日益增强,各基本因素之间发生冲突,从而产生了bala (能量)。]

1-11 Dehakendrikáńi parińámabhútáńi baláni práńáh.

deha = 身体、结构;kendrikáńi (形容词。) = 向心运动或惯性运动;parińámabhútáńi (形容词。) = 合力;baláni = 力量;práńáh (复数。) = 生命能量,即多种力量的统称

[在物理结构中形成核心并维持其整体性的内力,被称为práńáh (生命能量)。]

1-12 Tiivrasaungharśeńa cúrńiibhútáni jad́áni cittáńu mánasadhátuh vá.

tiivra = 过度的;saungharśeńa (第三种情况) = 通过碰撞的方式;cúrńiibhútáni = 被粉碎;jad́áni (复数。) = 原始因素;cittáńu = 灵质颗粒:citta (心理客观性) +anu (微小颗粒);mánasa = 心灵;dhátuh = 物质、元素;vá = 或者

[由于过度碰撞,一些原始物质被粉碎,从而产生了cittáńu (外质颗粒),也就是意识物质。]

1-13 Vyaśt́idehe cittáńusamaváyena cittabodhah。

vyaśt́i = 个体、单元;dehe (第7种情况) = 在结构中;cittáńu = 外质颗粒;samaváyena (第3个) = 通过组合的方式;bodhah = 感觉、感知

[通过单元结构中胞质颗粒的结合,citta (客观的思维)的感受便逐渐形成。]

1-14 Cittát guńávakśaye rajoguńaprábalye aham。cittát (第5种情况) = 来自citta;avakśaye = 处于衰退之中;rajoguńa = 变化力量;prábalye = 处于主导地位;aham = 行动者意识,行动者“我”,或所有者“我”

[随着guńas的影响逐渐减弱,rajoguńa开始占据主导地位,aham (行动力)便从citta中演化而来。]

1-15 Súkśmábhimukhinii 生成 ahaḿtattvánmahat。

súkśma = 微妙的;abhimukhinii = 朝向;gatir = 运动;udaye = 开始;ahaḿtattván (第5种情况) = 来自ahaḿtattva;mahat = “I” 感觉

[在进一步向微妙层面发展的过程中,mahat由ahaḿtattva演变而来。]

1-16 Cittádahaḿprábalye buddhih.

cittát (第5种情况) > citta;ahaḿprábalye (第7种情况) = 当 aham 处于优势地位时;buddhih=智力

[当 aham 大于 citta 时,buddhi (智力) 会发生变化。]

1-17 Ahaḿtattvát mahadprábalye bodhih.

ahaḿtattvát (第5种情况) = 来自 ahaḿ;mahadprábalye (第7种情况) = 当 mahat 占优势时;bodhih = 直觉

[当 mahat 大于 aham 时,bodhi (直觉) 会发生变化。]

1-18 Mahadahaḿvarjite anagrasare jiivadehe latágulme kevalaḿ cittam.

1-19 Mahadvarjite anagrasare jiivadehe latágulme cittayuktáham.

1-20 Prágrasare jiive latágulme mánuśe mahadahaḿcittáni.

varjite = 无;anagrasare = 未发育的;jiivadehe (第7种情况) = 存在于生物体或活的构造中;latágulme (第7种情况) = 存在于藤本植物和灌木中;kevalam = 仅;cittayuktáham = citta以及aham;prágrasare (形容词。) = 已发育的;mánuśe (第7种情况) = 存在于人类体内;mahadahaḿcittáni (复数。) = mahat、aham以及citta

[在[[未开发的]]的生物体中,有藤本植物和灌木,而aham与mahat尚未进化出现,仅有citta存在。]

[在[[未开发的]]生物体中,存在着藤本植物和灌木,而mahat尚未进化出现,同时还有aham以及citta。]

[在成熟的生物体中,无论是藤本植物和灌木,还是人类体内,都存在mahat、aham和citta。]

1-21 Bhúmávyápte mahati ahaḿ cittayorprańáshe saguńásthitih savikalpasamádhih vá.

Bhúmá = 宏大心灵,宇宙性的Mahat;vyápte = 被渗透;mahati = 进入mahat;ahaḿcittayor (第6种情况,双数) = 属于aham与citta;prańáshe (第7种情况) = 处于解体状态,saguńa = 与guńas一同,具有限定性、确定性;sthitih = 状态,savikalpa = 与vikalpa一同,或与心理思维或情感一同;samádhi = 吸收,与目标合而为一:sama (相同) + adhi (目标)

[当 aham 与 citta 合并为宏观的 Mahat 时,这一合并过程被称为 saguńásthiti 或萨维卡尔帕 samádhi。]

1-22 Átmani mahadprańáshe nirguńásthitih nirvikalpasamádhih vá.

átmani = [[进入]] Átman,即“灵魂”;mahadpránashe (第7种情况) = 在mahat的消解之中;nirguńa = 没有guńas,无资格,不确定;sthitih = 状态,nirvikalpa = 无vikalpa,即没有思维或情感;samádhi = 吸收,与目标合而为一:sama (相同) + adhi (目标);va = 或

[当 mahat 与 Átman 合并时,它便被称为 nirguńásthiti (无对象状态),或称 nirvikalpa samádhi (心灵陷入难以确定的沉浸状态,或完全停止运转的状态)。]。

1-23 Tasyastitih amánasikeśu。

tasya = 其中包含 (关于无分别的samádhi);sthitih = 状态;amánasikeśu = 超出心灵之外

[这个状态 (关于无分别的samádhi) 超出了心智的范畴。]

1-24 Abhávottaránandapratyayálambaniirvrttih tasya pramáńam。

abháva = 虚无;uttara = 之后;ánanda = 极乐;pratyaya = 坚定的信念;álambaniih = 庇护、支持;vrttih = 心理倾向;tasya = 它的(nirguńa 的稳定性);pramáńam = 证明

[这种空明状态之后所留下的持久愉悦,正是该状态的存在证明,也是让人对该状态产生坚定信念的依据。]

1-25 Bhávah bhávátiitayoh setuh Tárakabrahma.

Bháva = 宇宙意识的体现,即由振动思维波构成的宇宙;Saguńa Brahma;Bhávátiita = 位于bháva、Nirguńa Brahma之外;tayoh = 两者之中的;setuh = 桥梁;Táraka = 赋予自由,能帮助人们跨越障碍。

[Nirguńa Brahma与Saguńa Brahma之间的桥梁被称为Táraka (解放) Brahma。]

第2章

2-1 Anukúlavedaniiyaḿ 很顺利。

anukúla = 和谐;vedaniiyaḿ = 在anáhata cakra状态下所体验到的瑜伽之心状态;sukham = 愉悦、幸福,即紧张的神经恢复正常时的感受

[一种愉悦的心理感受被称为幸福。]

2-2 Sukhánuraktih paramá jaeviivrttih.

sukha = 幸福;ánuraktih = 深情、爱、奉献、渴望:anu – rańj (颜色) + ktin (指的是心灵因渴望某物体的振动色彩而产生的心理色彩变化);paramá = 至高无上;jaevii = 生物;vrttih = 天性倾向

[对幸福的执着是生物生存的首要vrtti (倾向性)。]

2-3 Sukhamanantamánandam。

sukha = 幸福;anantam = 无尽的;ánandam = 极乐 [无尽的幸福就是ánanda (幸福)。]

2-4 Ánandaḿ Brahma ityáhuh。

ánandaḿ = 极乐;Brahma = 至高意识;ityáhuh = 被称为:iti + áhuh (从字面意义上讲,“正是如此,人们是这么说的”)

[这个ánanda被称为Brahma。]

2-5 塔斯米努帕尔布德赫 paramá trśńánivrttih。

tasmin = 即在此时;upalabdhe (第7种情况) = 在实现之时;paramá = 最高的、主要的;trśńa = 口渴;nivrttih = 完全满足,欲望的终结

[一旦获得(Brahma),所有的渴望都将得到永久的满足。]

2-6 Brhadeśańáprańidhánaḿ 即法。

Brhat = 伟大;eśańa = 愿望以及为实现它而付出的努力;prańidhánaḿ = 追逐;ca = 和;dharmah = 基本特征

[渴望并追逐伟大之人,便是dharma。]

2-7 Tasmáddharmah sadákáryah。

tasmád (第5种情况) = 因此,从字面意义上讲“就是从那个”;dharmah = 基本特征;sadá = 总是;káryah = 需要加以实践

[因此,应当始终践行dharma。]

2-8 Viśaye puruśávabhásah jiivátmá。

viśaye (第7种情况) = 位于物体之中;Puruśa = 意识,avabhásah = 反思;jiivátmá = 统一灵魂

[单位对象中Puruśa的反射被称为jiivátmá (个体灵魂)。]

2-9 Átmani sattásaḿsthitih。

átmani = 存在于 átman 中;sattá = 实体;saḿsthitih = 与之共存,最终得到证实

[每个实体最终都会被嵌入到Átman中。]

2-10 Otahprotah yogábhyáḿ saḿyuktah Puruśottamah.

otah = 个体;protah = 集体;yogábhyáḿ (双重) = 通过两种类型的关联;saḿyuktah = 相连;Puruśottamah = 宇宙核心

[Puruśottama与每个实体分别关联,同时也与所有实体整体关联。]

2-11 Mánasátiite anavastháyaḿ jagadbiijam。

mánasátiite = 超出思维范畴;anavastháyáḿ (第7种情况) = 处于不存在状态;jagat = 宇宙;biijam = 种子

[宇宙的种子存在于心灵之外,处于心灵无法理解的状态之中。]

2-12 Saguńát srśt́irupattih。

saguńát (第5种情况) = 来自“合格意识”;srśt́ir = 创造;utpattih = 起源、诞生

[它的创造源自 Saguńa Brahma。]

2-13 Puruśadehe jagadábhásah。

Puruśa = 意识;dehe (第7种情况) = 存在于身体之中,存在于结构之中;jagat = 宇宙;ábhásah = 反射、表象、外观

[宇宙在认知体之中形成。]

2-14 Brahma Satyaḿ jagadapi satyamápekśikam. satyaḿ = truth, unchanging; jagat = universe; api = also; ápekśikam = relative

[Brahma就是绝对真理;宇宙也是真理,但属于相对真理。]

2-15 Puruśah akartá phalasákśiibhútah bhávakendrasthitah guńayantrákashca.

Puruśah = 意识;akartá = 非行作者;phala = 果实,行为的结果;sákśii = 目击者;bhútah = 实体;bháva = 存在,Saguńa Brahma;kendra = 核心;sthitah = 状态,位置;guńayantrakashca = 以及guńas的掌控者

[Puruśa不采取任何行动,(直接地)也不行动,但它是各种行为与反应的见证者;位于Saguńa Brahma的核心位置,它是guńas的控制器。]

2-16 Akartrii viśayasaḿyuktá buddhih mahadvá.

akartrii = 不作为者;viśaya = 对象;saḿyuktá = 与……相关联,与……结合;buddhih mahadvá = buddhitattva或mahattattva

[buddhitattva或mahattattva本身并非执行者,但仍与各种对象相关联。]

2-17 Ahaḿ kartá pratyakśaphalabhoktá。

ahaḿ = 行动者 “I”;kartá = 行动者;pratyakśa = 直接行动;phala = 果实,即行动的成果;bhoktá = 享受者 (也就是说,那个得到行为结果的人)

[aham是行动者,直接享受或承受行动的后果。]

2-18 Karmaphalaḿ 城市。

karma = 行动;phalaḿ = 行动的成果,即果实;citta = 目标 “I”

[citta表现为行动的结果形式。]

2-19 维克塔恰伊塔西亚的 púrvávasthápráptirphalabhogah。

vikrta = 被改变的、被转化的、被调整的;cittasya (第6种情况) = 属于citta的;púrva (形容词。) = 之前的;prápti = 成就、所得;phala = 果实,行为的结果;bhogah = 享受 (或遭受痛苦)

[扭曲的citta恢复到原始状态的过程,就是体验行为所带来的结果——无论是快乐还是痛苦。]

2-20 上升至 rasátalah 的天空。

na = 否;svargo = 天堂;rasátalah = 地狱

[没有天堂,也没有地狱。]

2-21 Bhúmácitte saiṋcaradháráyáḿ jad́ábhásah。

Bhúmácitte = in Macrocosmic citta; saiṋcara = extroversive movement; dháráyáḿ (7th case) = in the flow; jad́a = matter; ábhásah = reflection, semblance, appearance

[在 saiṋcara 的流动中,物质在宇宙级的 citta 中形成形态。]

2-22 Bhútalakśańátmakaḿ bhútabáhitaḿ bhútasaungharśaspandanaḿ tanmátram.

bhúta = 被创造出的对象,基本要素;lakśańa = 符号或标记;átmakam = 由……构成;báhitam = 由……承载;saungharśa = 冲突;spandanam = 振动;tanmátram = “中最微小的量或分数,” (基本因素之中),超感官推断,通用本质:tan (那个) + mátra (极微小的数量)

[Tanmátras (bhútas的微观微粒,或基本因子)代表bhútas,由bhútas携带,是由bhútas内部的碰撞产生的振动所形成的。]

2-23 Bhútaḿ tanmátreńa 参与比赛。

bhútaḿ = 基本因素;tanmátreńa (第三种情况) = 由tanmátras决定;pariciiyate = 被识别或已知

[bhútas会通过其对应的tanmátras被识别。]

2-24 Dvárah nád́iirasah piit́hátmakáni indriyáńi.

dvárah = 入口,通道;nád́ii = 神经;rasah = 液体;piitha = 控制点,即大脑中与citta相连的器官所在位置;átmakáni = 由……组成;indriyáńi (复数。) = 器官

[感官(器官)是由器官的通道、神经、神经液以及器官(在大脑中)的相应调节机制piit́has (座位)共同构成的。]

第3章

3-1 Paiṋcakośátmiká jaeviisattá kadaliipuśpavat。

paiṋca = 五;kośa = 层、鞘;átmiká = 由……组成;jaeviisatta = 生物;kadalii = 车前草;puśpavat (第5种情况) = 像花一样

[生物是由五个kośas (心灵的层次)构成的复合体,就如同芭蕉花由(带着它的花瓣)构成一样。]

3-2 Saptalokátmakaḿ 梵天之志。

sapta = 七;loka = 地区、领域;átmakaḿ = 由……组成;manah = 心智

[宇宙意识是由七个世界 (层次,世界) 组合而成的。]

3-3 Kárańamanasi diirghanidrá marańam。

káráńa = 因果关系;manasi (第7种情况) = 心中;diirgha = 长;nidrá = 睡眠;marańam = 死亡

[在因果心中的长眠即是死亡。]

3-4 马诺维克蒂赫 vipákápekśitá saḿskárah。

manovikrtih = 心理扭曲;vipáka = 反应;apekśitá = 需要表达的潜力;saḿskárah = 潜在的反应

[正在等待表达的思维物质的扭曲形态 (也就是说,一种潜在的反应。) 被称为 saḿskára。]

3-5 Videhiimánase na kartrtvaḿ na sukháni na duhkháni.

videhiimánase (第7种情况) = 在无形的意识之中;na = 否;kartrtvaḿ = 行为主体性;sukháni = 快乐;duhkháni = 痛苦

[在无形的意识中,没有行为主体,也没有快乐或痛苦的感觉。]

3-6 Abhibhávanát cittáńusrśt́apretadarshanam。

abhibhávanát (第5种情况) = 来自高度集中的思维;cittáńu = 心灵物质;srśt́a = 被创造出来的;preta = 鬼魂;darshanam = 视觉

[鬼魂的景象是由高度集中的思维中的cittáńu (思维内容)所形成的。]

3-7 Hitaeśańápreśito'pavargah。

hita = 福利、全面发展;eśańá = 欲望、意志;preśitah = 被驱使;apavargah = 行为的报应,行为完成之后的阶段

[对某一行为的回报,是由对福祉的(神圣的)渴望所指引的。]

3-8 Muktyákáuṋkśayá sadgurupráptih。

mukti = 解放;ákáunkśayá (第三种情况) = 出于强烈的渴望;sadguru = 完美的大师;práptih = 得到,成就

[出于对mukti (解放)的强烈渴望,人们便能获得自己的圣师(完美的大师)。]

3-9 恰为梵天之师 náparah。

Brahmaeva = 仅 Brahma;guruh = 古鲁;ekah = 一;na = 没有;aparah = 其他

[只有Brahma才是大师,没有其他人。]

3-10 Bádhá sá yuśamáná shaktih sevyaḿ sthápayati lakśye.

bádhá = 障碍;sá (女性。) = 那个;juśamána = 帮助;shaktih = 力量;sevyaḿ = 那个[[理应被服务。]]的人;sthápayati = 建立;lakśye (第7种情况) = 在目标之中,处于目的状态

[障碍正是帮助人达成目标的助力。]

3-11 Prárthanárcanámátraeva bhramamúlam。

prárthana = prayer; árcaná = worship; mátraeva =certainly only; bhrama = error; múlam = root, cause

[祈祷与仪式性的崇拜成了令人困惑的根源。]

3-12 Bhaktirbhagavadbhávaná 与 stutirnárcaná。

bhaktih = 崇拜之心;Bhagavad = 神;bhávaná = 构思;na = 不,没有;stutih = 赞美之词、颂歌;arcaná = 崇拜行为

[虔诚是对上帝的思索,而非对上帝的谄媚或仪式性的崇拜。]

第4章

4-1. Triguńátmiká srśt́imátrká asheśatrikońadhárá。

triguńa = three guńas or binding principles; átmiká = composed of; srśt́i = creation; mátriká = mother; asheśa = endless; trikońa = “three corners”, triangle; dhárá = flow

[三属性原始力量(万物的创造者)以无尽的三角形形态持续流动。]

4-2. Tribhúje Sá svarúpaparińámátmiká.

tribhúje (第7种情况) = 在三角形中;Sá = 她,Prakrti;svarúpa = 严格来说就是“其自身的形态”,即自我存在;parińáma = 变化;átmika = 由……构成

[在力量三角中,Prakrti的三个属性处于不断相互转化的状态。]

4-3. Prathamá avyakte Sá Shivánii kendre ca Paramashivah.

prathamá = 第一;avyakte (第7种情况) = 处于未显现状态;Sá = 她,Prakrti;Shivánii = 第一阶段中Prakrti的名称(Shiva的阴性形式);kendre (第7种情况) = 在核心之中;ca = 而Paramashivah = 至高意识,即Puruśa的名称

[在第一阶段(尚未进入实际显现的阶段)中,Prakrti被称为Shivánii,而位于核心处的见证者Puruśa则被称为Paramashiva。]

4-4. Dvitiiyá sakale prathamodgame Bhaeravii Bhaeraváshritá.

dvitiiyá = 第二;sakale = 声音柔和;prathama = 第一;udgame (第7种情况) = 发芽;Bhaeravii = 第二阶段中Prakrti的名称;(Bhaerava的阴性形式);Bhaerava = 第二阶段中Puruśa的名称;áshritá = 受保护处

[在第二阶段,当进化的萌芽出现时,Prakrti被称为Bhaeravii,而作为见证者的Puruśa则被称为Bhaerava。]

4-5. Sadrshaparińámena Bhavánii Sá Bhavadárá.

sadrsha = 相似;parińámena (第三种情况) = 来自结果;Bhavánii = 此阶段Prakrti的名称(Bhava的阴性形式);Sá = 她,Prakrti;Bhavadárá = Bhava的妻子 (Puruśa)

[在振动世界中,存在着一系列曲率相似的序列 (同质性)。 此处,Prakrti被称作Bhavánii,而作为见证的Puruśa则被称作Bhava。]

4-6. Shambhúliuṋgát 即为其实际表现。

Shambhú = 自主创建的控制器;liuṋgát (第5种情况) = 来自符号;tasya = 它的、他的;vyaktih = 表达

[创作过程始于Shambhúliuṋga。]

4-7. Sthúliibhavane nidritá sá kuńd́alinii。sthúliibhavane (第7种情况) = 正处于粗化处理中;nidritá = 正在睡觉;sá = 她;kuńd́alinii = 盘绕的蛇形物

[在最原始的状态下,潜伏在Svayambhúliuṋga之中的paráshakti被称为kuńd́alinii (“盘绕的蛇形物”)。]

4-8 Kuńd́alinii sá múliibhútá rńátmiká.

kuńd́alinii = literally “coiled serpentine”; sá = she; múliibhútá = fundamentally; rńátmiká = negative

[kuńd́alinii就是(力量)的本质负面性。]

第5章

5-1. Varńapradhánatá cakradháráyám.

varńa = 颜色 (此处,心理色彩);pradhánatá = 主导性;cakra = “循环”,即社会循环;dháráyám (第7种情况) = 处于流动之中

[在社会循环的运转中,总有一个阶级处于主导地位。]

5-2. Cakrakendre sadvipráh cakraniyantrakáh。

cakrakendre (第7种情况) = 位于社会循环的核心之中;sadviprah (复数。) = 在字面意义上“确实 vipras”;cakra = 循环;niyantrakáh = 控制器

[位于社会循环的核心,萨德维普拉斯掌控着社会循环。]

5-3. Shaktisampátena cakragativardhanaḿ krántih.

shakti = 力量;sampátena (第三种情况) = 通过施加作用力;cakra = 循环;gativardhanaḿ = 以加速运动;krántih = 进化:kram (跨越某些障碍)

[通过施加力量来加速社会循环的变动,被称为“进化”。]

5-4. Tiivrashaktisampátena gativardhanaḿ 是贵宾账号。

tiivra = 巨大的、突然的且极其严重的;shakti = 力量;sampátena (第三种情况) = 通过施加力;gativardhanaḿ = 加速……的运动;viplavah = 从字面意义上讲“淹没一切的流动”,即革命

[通过施加巨大力量来加速社会循环的变动,被称为“革命”。]

5-5. Shaktisampátena vipariitadháráyáḿ vikrántih.

shakti = 强制力;sampátena (第三种情况) = 通过应用;vipariita = 相反的;dháráyáḿ (第7种情况) = 在流动中;vikrántih = 逆向进化

[通过强行手段扭转社会循环的运行方向,被称为“逆向进化”。]

5-6. Tiivrashaktisampátena vipariitadháráyaḿ prativiplavah。

tiivra = 巨大的;shakti = 力量;sampátena (第三种情况) = 通过运用;vipariita = 相反的;dháráyáḿ (第7种情况) = 在流动中;prativiplavah = 反革命

[通过施加巨大力量来扭转社会循环的走向,被称为“反革命”。]

5-7. Púrńávartanena parikrántih.

púrńa = 完整状态;ávartanena (第三种情况) = 带有旋转或转动;parikrántih = 循环运动完成

[社会循环的一次完整旋转被称为“边缘演化”。]

5-8. Vaecitryaḿ prákrtadharmah samánaḿ na bhaviśyati.

vaecitryaḿ = 多样性、丰富多彩;prákrta = 自然的,与Prakrti (最高行动准则)相关;dharmah = 特征、根本法则;samánaḿ = 两个不同对象在质与量上的相等价值;na = 不,没有;bhaviśyati = 将会

[多样性,而非同一性,才是自然法则。]

5-9. Yugasya sarvanimnaprayojanaḿ sarveśáḿ vidheyam.

yugasya (第6种情况) = 某个年龄阶段;sarvanimnaprayojanaḿ = 最基本的生活必需品;sarveśáḿ = 所有事物;vidheyam = 应当予以提供

[每个人都应享有达到某一年龄的最低要求保障。]

5-10. Atiriktaḿ pradátavyaḿ guńánupátena.

atiriktaḿ = 剩余货物;pradátavyaḿ = 应予以分配;guńánupátena = 按照贡献程度决定

[多余的财富应当根据有功之人的功绩大小,分配给他们。]

5-11. Sarvanimnamánavardhanaḿ samájajiivalakśańam.

sarvanimnamána = 最低生活标准;vardhanaḿ = 增长;samájajiiva = 社会活力;lakśańam = 指标,迹象

[提高人民的最基本生活标准,是社会充满活力的体现。]

5-12. Samájádeshena viná dhanasaiṋcayah akartavyah.

samája = 社会;adeshena (第三种情况) = 通过给予指示或命令,通过批准;viná = 没有;dhana = 财富;saiṋcayah = 积累;akartavyah = 不应该做

5-13. Sthúlasúkśmakárańeśu caramopayogah prakartavyah vicárasamarthitaḿ vańt́anaiṋca.

sthúla = 平凡的、粗糙的;súkśma = 超凡的,与原子结构相关;kárańeśu (第7种情况,复数。) = 原始的因果因素;carama = 最大值;upayogah = 利用;prakartavyah = 必须严格执行,不得有任何偏差;vicára = 理性判断,由良知支撑的判断;samarthitaḿ = 由……支撑;vańt́anam = 分配;ca = 和

5-14. Vyaśt́isamaśt́isháriiramánasádhyátmikasambhávanáyáḿ 真是糟糕透顶。

vyaśt́i = 个体;samaśt́i = 集体;sháriira = 身体 (此处既有个体,也有集体。);mánasa = 精神体 (个人与集体两者皆然);ádhyátmika = 属于 átmá 的,灵性体 (个人与集体两者皆然);sambhávanáyáḿ = 已经获得及可以获得的潜能;carama = 最大值;upayogah = 利用;ca = 和

5-15. Sthúlasúkśma kárańo’payogáh susantulitáh vidheyáh.

sthúla = (这里),二者都属于世俗与物质层面;súkśma = (这里),二者都属于精神与超世俗层面;kárańa = 精神层面的、最根本的因果因素;upayogáh (复数。) = 利用;susantulitáh (复数。) = 平衡的;vidheyáh (复数。) = 应当妥善处理。

5-16. Deshakálapátraeh upayogáh parivarttante te upayogáh pragatishiiláh bhaveyuh.

deshakálapátraeh = 空间、时间与人;upayogáh = 利用;parivarttante = 变化;te = 那些;upayogáh = 利用方式;pragatishiiláh = 逐步的;bhaveyuh = 应当或必须

Pragatishiila upayogatattvamidaḿ sarvajanahitárthaḿ sarvajanasukhárthaḿ pracáritam.

pragatishiila = 进步的;upayoga = 利用;tattvam = 理论;idaḿ = 这个;sarvajana = 所有人;hitárthaḿ = 为了全面的福祉与安康;sukhárthaḿ = 为了全面的幸福;pracáritam = 被传播开来

[这就是渐进利用理论,其宗旨是为所有人的幸福与全面福祉而服务。]

SÚTRA. 从字面意义上讲,“线程” (在上面可以串缀许多珍贵的思想珍宝);即格言。
SVAYAMBHÚLIUNGA. 人体中负面或粗糙特性的极致体现。

TAMOGUŃA. 请查看 GUŃAS。
TANMÁTRA. 从字面意义上讲,“极其微小的那一小部分,”也就是物质中某个最基本因素的那一小部分。 同样也被翻译为“通用本质”或“推演波动”。 各种类型的tanmátras能够传递听觉、触觉以及(愿景)、味觉和嗅觉的信息。
TÁRAKA BRAHMA. 至高意识在其解放层面的体现。

VAESHYA. 具有贪欲心态的人,资本主义社会阶级的一员。
VIDYÁ SHAKTI. 向心力,或称内聚力;指向核心意识的吸引力;宇宙运作原理中引导事物从粗糙状态向微妙状态发展的那一方面。
VIPRA。 用智慧控制他人的人,属于知识型社会阶层。
VRTTI。 心理倾向。

YOGA. 一种能让 ÁTMAN 与 PARAMÁTMAN 实现统一的灵修方法。
