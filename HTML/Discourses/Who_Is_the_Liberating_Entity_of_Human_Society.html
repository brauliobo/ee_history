谁是人类社会的解放力量
1979年2月18日 DMC, 班加罗尔

今天讨论的主题是:谁是人类社会的解放者? 有人说,人类是通过神秘力量获得救赎的。 这可能是事实,也可能不是。 什么是神秘力量? 那是人们通过神秘修行、通过他们的“邪教”所获得的力量。 但它们需要灵感,而这种灵感源自个人,而非任何非个人实体。 此外,在追求灵性之路的进程中,其最终目标、终极境界无疑是救赎。 因此,必定存在一位主宰,一个掌控着那个顶点的存在。 当任何人与终极境界合为一体时,便能获得救赎。 因此,终极之主便是那能带来救赎的个体 –;没有他的恩典,没有他的帮助,无人能够获得救赎。

那么,那个具有解放精神的个体是谁呢? 你必须记住,每一个实体都渴望获得解放。 他们不仅渴望获得解放,还渴望获得永恒性质的解放,那便是救赎–,而非mukti,而是vimukti或mokśa。 那个muktidátá是谁,那个带来解放的人? 一些性格消极的人认为这是时间因素造成的。 “总会有我们获得救赎的那一天。”这样的说法表明这些人已经产生了懒惰的心理:他们不想做任何事,因此才依赖时间因素。 但你必须记住,这个时间因素是一个相对因素:它在相对论的范畴内起作用,存在于众多有生命与无生命的实体之中。 当时间因素本身也受到束缚时,它又怎可能成为救赎的根源?

那么,时间究竟是什么? 时间是对行为变动性的心理度量。 如果存在心理测量,那就必须有许多单元心灵来进行测量,同时还必须存在–这种运动,至少需要三个实体。 所以是 kála 或 kála shakti 或者,时间无法成为解放者。 即使 Mahákála 也会与你一同玩耍,但它无法赋予你自由;– 也不在它的能力范围之内。

那么,是命运还是偶然在解放人们? 其实,“命运”是个误称。 无论你做什么,都必然会引发相应的反应;而当你不知道最初的行动是什么时,那种反应就被称为“命运”。 假设你的手指接触到火:在感受到反应、经历疼痛时,你知道其成因,这种情况下你就不会说这是命运。 但当你不知道最初的行动是什么时,你就会将其称为命运。 那么,命运也不可能是muktidátá。

还有人说mukti是偶然的,但这个世界上没有什么是偶然的,–,一切都是注定发生的。 只有当我们不知道事故的起因,或者起因在短时间内就转化为实际行动时,我们才会将其称为事故。 因此,我们不可能偶然获得解脱:那是个愚蠢的想法。

那么,由quinquelemental因子构成的这个宇宙应当被视为muktidátá,还是解放者呢? 不,绝对不行。 它们正是导致越来越多束缚与越来越多麻烦的根源。 如果你崇拜这些paiṋcabhútas,即这五种根本要素,你的存在本身就会随之改变:原本如人类般的荣耀生命将会变成石头或黄金。 (无论是石头还是黄金,束缚带来的痛苦都是一样的。). 所以这些quinquelemental因子也不是muktidátá。

那么,因果矩阵就是解放者吗? 不,绝对不行。 因果矩阵只有在因果意识、因果认知的明确许可下才能发挥作用。 没有他的批准,因果矩阵便无法采取任何行动。 所以,就连因果矩阵也不是创造的原因。

那么,创造宇宙的 Saguńa Brahma,就是 muktidátá 吗? 不,Saguńa Brahma也不是解放者,因为他自己也受Prakrti的束缚,事实上,这就是我们看到这个充满多样性的宇宙的原因。 所以 Saguńa Brahma 也不是解放者。

那么,谁才是解放者呢? muktidátá不应受Prakrti的束缚,但它应与所表达的宇宙保持紧密联系。 与所展现的世界保持着紧密联系的意识,便是知晓那个被展现宇宙中所有痛苦、所有悲伤、所有幸福与所有荣耀的muktidátá –。 他应当与宇宙融为一体,否则便无法体会受苦人类的悲伤与痛苦。 在Saḿskrta (táraka = trae + ńak, the liberating faculty)中,muktidátá被称为Táraka Brahma。 táraka这个字样仅出现在他的名字前,而不出现在Saguńa Brahma或Nirguńa Brahma 或任何其他实体的名字前。 Krśńa大人说过:

Paritráńáya sádhúnáḿ vinásháya ca duśkrtám
Dharmasaḿsthápanártháya sambhavámi yuge yuge.

再说一次:

Api cet sudurácáro bhajate mámananyabhák
So’pi pápavinirmukto mucyate bhavabandhanát.

Paritráńáya sádhúnám:主为sádhus的paritráńa而来。 paritráńa的含义是什么? Trae + lyut́ = tráńa。 Tráńa意味着给予救济,但他并非仅仅为了给予救济而来。 他前来是为了paritráńa,也就是为了具有永久性质的tráńa。 Paritránáya sadhúnám:sádhus是谁? 仅仅穿着白色或藏红色的长袍,并不能使人成为sádhu。

Játasyahi jagati jantavah sádhújiivitáh
Ye punarneha jáyante sheśáh jat́haragardhavá
Práńáh yathátmano’bhiiśt́áh bhútánámapite tathá
Átmaopanyena bhútánáḿ dayáḿkurvanti sádhavah.

那些内心与外在都极其纯净的人,就是sádhus;而其他人,正如shloka所说,不过是披着人皮的驴子罢了;gardabha的意思就是“驴子”。

Práńáha yathátmano’bhiiśt́áh bhútáńamapi 与 tathá:每一个存在的生命对他们来说都极为珍贵;他们都非常珍视自己的生命。 那些与–一样怀有对其他生物的慈爱之情的人,也就是说,他们认为“正如我的生命对我而言极为珍贵、备受珍视一样,其他生物的生命对我来说也同样极为珍贵”,–,这类人被称为sádhus。 所以主说,Paritránáya sádhúnám,为永久缓解这些sádhus;vinásháya caduśkrtám (vi – nash + ghaiṋ = vinásha)的困境。 Vinásha即viśheśa násha,“彻底毁灭”,此后便再无生命存在的可能。

Vinásháya 等于 duśkrtám。 Duśkrtám指的是那些从事不良活动的人。 那么,哪些是不受欢迎的活动呢? 那些不被Parama Puruśa所喜欢的活动,都是不可取的。 对小偷来说,偷窃或许并非坏事,但对 Parama Puruśa 来说却是不可取的;因此,那些从事偷窃行为的人就是 duśkrtám。 Dharmasaḿsthápanártháya sambhavámi yuge yuge. Saḿsthápana的意思是“将某个实体放置到正确的位置。”仅仅放置该实体即为sthápana,而将其放置到正确位置则为saḿsthápana。 Dharmasaḿsthápanártháya sambhavámi 非常非常:“为了将 dharma 放在正确的位置。”此处,Krśńa 君并未说 bhavámi 非常非常;bhavámi 的含义是诞生,即在物质世界中得以体现。 但他没有说出bhavámi。 他说 sambhavámi。 Sambhavámi means samyak rúpeńa bhavámi. 每一个实体与粒子都是祂的显现,因此祂每日都在成千上万的生命中诞生 – 每一天,祂都是 bhavámi。 所以他不说bhavámi,而说sambhavámi。 “我凭借特殊的能力以一种特殊的方式表达自己。”

那他究竟是谁? 他是每一位心灵追求者所抵达的终极境界的主人。 掌控并引领人们走向解放的主,以一种特殊的形式降临于此。 他什么时候会来? 巨大无比。 “Yuge”指的是世界面临如此严峻的危机,以至于普通人类乃至圣贤都无法解决问题的时刻。 在Saḿskrta中所称的“yugasandhi”这类关键时刻,他必须降临。 Sambhavámi 时代啊时代:他说,“我会在每一个时代降临。”所谓时代,指的是人类社会发展的一个阶段结束、另一个阶段开始的那段时期:那个转折点就被称为时代。

因此,人们必须记住:通过自身的灵修未必能够获得救赎,还得依靠祂的恩典。 正因祂通过自己的ota与prota yoga与每一个被显现的实体合而为一,所以祂才是你最亲近、最珍视的人。 你可以完全信赖他,而你对他的这种信赖就被称为sharańágati。 这个sharańágati就是对所有灵性问题的唯一答案。 因此他明确说道:

Api cet sudurácáro bhajate mámananyabhák
So’pi pápavinirmukto mucyate bhavabandhanát.

Daevii hyeśá guńamayii mama Máyá duratyayá;
Mámeva ye prapadyante Máyámetáḿ taranti te.(1)

“这个Máyá是一股危险的力量。 Máyá那双灵巧的双手制造出了许多问题,而这些问题都很危险:Aghat́ana、pat́iiyasii Máyá。 人类很难克服Máyá的影响。 但我就在那里。 那些求助于sharańágati、在我这里获得庇护的人,将能够轻松度过生活中的种种困难、忧虑与焦虑。 即便是罪人也应依靠我 – 我会在此帮助他们。”

Útámrtasyesháno:他不仅是天界之主,也是地狱之主。 Útá的意思是地狱。 即便是个地狱中的罪人,也不应心神不安,因为有地狱之主与他同在。 Api cet sudurácáro bhajate mámananyabhák. “即便最邪恶的罪人求助于sharańágati以彻底臣服,那么pápavinirmukta –,他们也将从各种罪孽中得到解脱”:mucyate bhavabandhanát。 “他们必须获得救赎,因为我是救赎的赐予者。”

脚注

(1) Bhagavad Giitá. –翻译。

1979年2月18日,班加罗尔,DMC
