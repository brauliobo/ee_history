发音 – 4 (论述4)
1983年7月10日, 加尔各答

帕尼尼通过特别关注声音,率先建立了语音学这门学科,而语音学是语文学中不可或缺的一部分。 虽然那是很久以前的事了,但其实也并非那么久远。 到那时,《梨俱吠陀》与《夜柔吠陀》的时代已经结束,而《阿闼婆吠陀》的时代正在延续。 他的语法以《夜柔吠陀》为依据,而非《梨俱吠陀》,因为到那时《梨俱吠陀》的发音方式已经消失了。 正因如此,他遇到了许多困难。

Panini根据语音学为ńa和śa的使用制定了特殊规则。 我之前指出过,《夜柔吠陀》的发音风格与《梨俱吠陀》的发音风格不同。 以 ńa 和 śa 的发音为例。 在说旁遮普语的地区及其周边地区,(在 Paeshácii Prákrta-speaking 地区) kśamá 的发音为 khamá,而非 kśamá。 这是《夜柔吠陀》的风格。 帕尼尼来自Gándhár (如今,一部分在巴基斯坦,一部分在阿富汗。)。 帕尼尼所处的时代,该地区的口语是Páshcáttya Prákrta。 这是帕尼尼的母语,也是现代普什图语的起源。

帕尼尼观察到,在某些地区,ńa的发音已自然演变为ŕhan 或者 nan。 他接受了ńa的这种自然发音。 例如,vipańi、báńijya、kalyáńa等等,都是以《夜柔吠陀》的发音方式来读的。

帕尼尼观察到,如果一个单词包含ra、r或śa,那么在它们的影响下,齿音na的发音会类似于脑音ńa。 在仔细考虑语音学因素后,他将此确立为ńa规则,例如dhárańá。 在这里,他遵循的是《夜柔吠陀》的发音规则,而非《梨俱吠陀》的,因为那时《梨俱吠陀》已经变成了dúrast [偏远地区]。(1) 在《梨俱吠陀》的风格中,dhárańá变成了dháraŕhán。 许多专家对dhárańá的发音是错误的。

帕尼尼运用符合心理规律的方法,为这方面制定了某些规则。 如果在任何复合词中,第一个词里含有ra、r或śa,那么第二个词中的na通常不会受到影响。 例如,harináma。 “hari”与náma这两个词之间有间隔。 因此,第一个词“hari”的ra值不会影响第二个词náma的na值。 也就是说,ná 仍然为 na。 然而,如果第一个单词包含前缀pra或pari,那么紧随其后的单词中的na就会变为ńa。 For example, parińáma, prańáma, prańaya, etc.

在某些情况下,第一个词中的ra、r或śa不会影响后面的词。 然而,下列单词中有些音素的发音很容易受到间隔的影响。(2) 如果后面的单词包含某种音素,使得第一个单词对第二个单词的影响得以延续,那么在这种情况下,第一个单词的ra会影响第二个单词,而na会变为ńa。 这类词中有一些已变成了例外:–、阿雅娜 (uttaráyańa)、ahna、(aparáhńa、púrváhńa。 but madhyáhna), úhinii (akśaohińii), grámiińa, sarváungiińa, súrpańakhá.

在某些情况下,第一个单词中的ra、r或śa在发音时不会影响第二个单词,例如parinirváńa。 如果 pra 出现在动词词根 nash 之前,则它不会产生任何显著影响,因此 prańásha 可以用 na 或 ńa 来表示。

如果元音或轻辅音位于 ra、r 或 śa 的正后或其间,那么它甚至会影响位置较远的 na。 在这种情况下,规则是:即使ra、r或śa并不紧接在na之后,也会影响na。 例如,váśpáyańa。 对于元音ka varga、ya、va和ha而言,即使它们相距甚远,甚至出现多次,远处的na也会变为ńa。

帕尼尼在其梵语语法中以这样的方式规定了ńa和śa的规则,使其完全基于语音特征。 但值得指出的是,这种发音方式早已存在,也就是说,人们过去就是那样发音的。 帕尼尼所做的只是为这种发音方式赋予了系统化的形式。 他将它纳入了公式的范畴之中。

孟加拉语在许多方面与梵语不同。 孟加拉语只有“sha”这个发音,没有śa 或者萨的发音。 不过,虽然śa没有独立的发音,但在特殊情况下其发音会略有差异。 例如,śańd́a,rákśasa。 在一种情况下,śa 的发音为 – śańd́a –,而在另一种情况下则发音为 – rákśasa (k + śa = kśa (卡))。 “Sa”仅以书面形式存在,没有独立的发音。 有些人会将拼写为“sha”的单词错误地发成一种扭曲的“sa”音。 人们喜欢拿这个开玩笑。 例如,syámavájárer Sasiivávu sasá khete khete sedin sásácchilen [那天,希扬巴扎尔的沙希先生在吃黄瓜时发出了威胁。]。(3) 另一个表明孟加拉语与梵语在发音方面存在诸多差异的例子是:在梵语中,当以“sa”开头的动词词根紧跟前缀“ni”时,可以用“śa”来替代“sa”。 因此在梵语中,niśáda和nisáda都是正确的(ni –,其词根带有ghaiṋ这一后缀)。 仅在孟加拉语中使用了niśáda。 如果有人将niśáda拼写成sa,那么一些专家很可能会认为这是错误的。 upaniśada和(upa –即– śad的词根,后缀kvip = 孟加拉语中的upaniśada)也是如此。 在梵语中,upaniśada和乌帕尼沙德都是正确的。 孟加拉语中有“sa”这个字母,但没有独立的发音,因此会尽可能避免使用它。

后缀shatr被用于动词词根的parasmaepadii之后,用以表示yá cale caleche [正在发生的事情]。 在《梨俱吠陀》时代,parasmaepadii与átmanepadii之间有着明确的界限。 当主语为自身时,使用átmanepadii;当主语为他人时,使用parasmaepadii。 凡是未明确说明是 [átma] 还是 para [其他] 的情况,均被视为 ubhayapadii。 《梨俱吠陀》中广泛使用了Átmanedpadii,而在《夜柔吠陀》中的使用则有所减少。 在《阿闼婆吠陀》中,它的使用实际上已完全消失。 帕尼尼的母语并非吠陀梵语,但他必须以吠陀经作为划分átmanepadii及parasmaepadii动词的依据,因此在这方面他遇到了一些困难。

通常很难分辨哪个是átmanepadii,哪个是parasmaepadii。 例如,动词词根 cal [表示“去”],ji [表示“胜利”]。 在《梨俱吠陀》中,它们是átmanepadii,例如:jayate – satyameva jayate [唯有真理能获胜]。 然而在现代梵语中,动词词根ji为parasmaepadii,因此为jayati。 当然,加上前缀后动词词根 ji 就是 átmanepadii,例如,vi – jayati = vijayate。 由于这些困难,他接受了使用ubhayapadii。

沃帕德瓦只接受了使用旁义格。 因此,将把shatr加到cal上,而非shánac (用于表示现在分词),因为在Laokika梵语中,动词词根cal属于parasmaepadii类型。 然而,经过深思之后,我终于想起了两千五百年前佛陀时代的一句梵文shloka,而átmanepadii (从劳基卡的意义上来说)中则使用了动词词根cal。 示例是:

Ihásane shuśyatu me shariiram
Tvagasthimáḿsaḿ pralayaiṋca yátu
Aprápyabodhiḿbahukalpadurlabháḿ
Naevásanát káyamatashcalisyate

因此,帕尼尼不得不接受ubhayapadii,因为cal动词词根 + shatr = calat。 例如,calat + citra = calaccitra。 因此,cal + shánac = calamána。 两者都是正确的。 请记住,shatr、shánac、átmanepadii、parasmaepadii、短元音、长元音与延长元音,以及发音为–的元音,所有这些都会随着时代的变化而改变。 他们过去如此做过,将来也会继续如此做。

在梵语中,后缀kvip用于表示“天性倾向”。 例如,gam + kvip = jagat [世界] 或 “其本质便是移动的。”。 然而,当其为连续的 [haye caleche] 时,后缀则为 shatr。 例如,gam + shatr = gacchat [前往]。 对于shánac而言,由于它是átmanepadii,因此即使然后 shánac无法保持很好的节奏也没关系。 也就是说,shánac具有轻快的节奏。 将 mán 或 án 添加到 shánac 中。 通常在这里,当原动词词根以辅音 (例如,sev) 结尾时,其第三人称复数形式则使用 lat́ (七)。(4) 在这种情况下,取代该ete的是与前述动词词根 sev (sevamána)一起使用的mána。 如果原动词词根以元音结尾(例如,shii),那么在lat́中为第三人称复数形式,á使用了te (shayáte)也是如此。 在这种情况下,如果将shánac加到动词词根shii上,那么就会用á无 (shayána)来代替áte。 就svabháva [天性倾向]而言,从连贯性角度考虑,梵语中不会使用同一动词的两种不同形式,但动词形容词则会使用这两种形式。 在英语中,动词形容词是通过添加后缀“ing”和“ed”等构成的。 然而,在印度语博杰普尔语中,表示自然倾向意义上的动词形式与表示“haye caleche”意义的动词形式是分开的。 例如,Rámka bhái paŕelá和Rámka bhái paŕatá。

通过这种方式,帕尼尼在语法、语音和节奏之间实现了和谐的协调,从而为众人带来了便利,而这并非易事。 沃帕德瓦增加了语言的轻盈感,但为了便于实现这种轻盈感,他反而使语法变得复杂。 帕尼尼所构建的语法体系极为严谨且优美,具有科学的框架。 没有[jo]这一纬度,因为它会在各处蜿蜒移动。(5)

现在让我们看看这种语音在阿拉伯语中会呈现什么情况。 在大多数欧洲语言中,“h”在单词开头时不发音。 例如,“酒店”。 在法语中,它的发音是“otel”。 然而在阿拉伯语中它并非无声。 有时会完整发音,有时则只部分发音。 在阿拉伯语中,如果一个单词之后有元音或<hewprs-quote-open id="1"/>h<hewprs-quote-close id="2"/>,那么就会在原本会发音或不会发音的<hewprs-quote-open id="3"/>h<hewprs-quote-close id="4"/>位置上插入第六格变格形式ul。 当存在发音清晰或不发音的辅音时,第六格的变化形式会随之该辅音的发音而改变。 例如,phajal + ul + rahaman = phajalur-rahamán。 这里的辅音“ra”只发部分音,因此无法读作“ul”;它变成了“phajalur”。 然而,ájij + ul + hak = ájijuahak,因为“hak”这个词中的辅音“ha”会被完整发音。 因此,这里的l被保留下来,形成了ájijulhak。 Najar + ul + islám = najarulislám,因为元音l的发音十分清晰。 然而,ájim + ul + sán = ájimusyán,因为这里的辅音“sa”发音清晰,所以“ul”被省略了。 同样地,sháms + ul + náhár = shámsunnáhár。

语法格言是按照正确且自然的发音来编排的,以便于发音。 发音风格是预先设定好的。 通过仔细聆听,语法学家在音节层面记录下这种发音。 正因如此,世界上所有语言都通过同一条纽带联系在一起;没有语音学,任何语言都无法向前迈出一步。 孟加拉语中也包含土耳其语词汇,此外还有阿拉伯语和波斯语词汇。 必须格外注意,才能正确发音这些单词。

在所有语言中,发音都会发生变化,以便与元音发音保持同步。 例如,在英语中,这个字母有二十一种不同的发音。 “a” 但在法语中只有一个,即孟加拉语的á。 在法语中,“Paris”的发音为párii –,其中的“s”是不发音的,因为法语的规则是:在大多数情况下,单词末尾的辅音不会被发音;只有当末尾的辅音是“c”、“f”、“l”或“r”时才会发音。 为了便于发音,会在其后加上一个元音音素。 很多人会错误地将法语单词madame拼写为“madam”。 如果用法语拼写这位女士的名字时省略末尾的“e”,那么它的发音就会变成mádán。 为了保持正确的发音,其结尾必须加上“e”。 在法语中,“my”的阳性单数形式是mon,阴性单数形式是ma。 复数形式为mes,因此madame的复数形式是mesdames。 有些人会误将此理解为“may-s-day-m-s”。

“在英语中,A”属于轻元音,因此如果前缀“a”之后出现动词词根,则第一个辅音会重复出现。 例如,“a + quire”。 此处,“quire”是核心动词,而“a”则是前缀。 在这种情况下,“q”应该出现两次,但由于无法发出双重的“q”音,因此用“c”来替代;这样就变成了“acquire”。 “获取”也是如此,但对于“需要”和“申请”的情况,辅音不会重复出现,因为“e”不属于轻元音。

梵语中也遵循这一规则。 它按照语音规则被加倍。 例如,tarań + apashyat = tarańńapashyat,也就是说,“他在游泳时看到了[看看吧]”。 (现在告诉我,在加尔各答的口语中应该用dekhla还是dekhle?应该是dekhle。在拉尔希孟加拉语中,这种情况下则用dekhlek。要记住,如果去掉拉尔希孟加拉语中的最后一个k,它就会变成加尔各答孟加拉语。当然,在这种情况下及物动词和不及物动词的形式是不同的。同样地,[他说话了]的口语形式不会是se balla,而是se balle。)

在法语中,定冠词(那)的阳性形式是le,阴性形式是la,复数形式是les。 然而在这里,当发生音节省略时,le、la和les的发音会发生变化。 在这种情况下,拼写练习就变得极为重要。 例如,“法语中的“men””并非“le am”,而是“lezam [les hommes]”。

英文单词“knife”源自法文单词kanife。 此处,英文字母 “k” 不发音。 然而,由于“knife”源自法语单词kanife,它的拼写中仍然包含“k”。

“H”在法语中位于单词开头时是不发音的,例如,“history” –的法语发音为istoire。 “在法语中,”“Hotel”这个词的发音是“otel”,而在英语中则保留了““h””的发音,因此其发音为““hotel””。 “医院”在法语中的发音是opital,而在英语中则是“hospital”。 然而,在“honour”这一情况下,法语式的发音方式onár在英语中得以保留。 即使是没有受过教育的法国人,也会遵循这些自然的发音习惯。

前缀的发音和拼写受元音发音风格的影响,后缀也是如此。 “pre” of “prefix” 是一个拉丁语前缀,而 “fix” 是一个动词词根。 因此,“pre” + “fix” 就构成了 “prefix”。 梵语中有二十个前缀。 “Suffix” 是通过将 “sub” 放在 “fix” 之前而得到的,也就是 “sub” + “fix”。 在这里,“b”变成了“f”,因为“b”属于中辅音,所以“后缀”就用两个“f”来拼写。 “f”在“后缀”中的形式是“b”的替代;第二个“f”则发硬音。

如果在词根后加上后缀,则称为“taddhita”;而对于带有后缀的动词词根,则称为krtprakarańa。 在将后缀加到词根或动词词根的这种krt或taddhita过程中,原始的词根或动词词根在某些情况下会导致辅音发生变化,有时则会导致元音发生变化。 例如,sarvajana + iin = sarvajaniin。 如果将 śńik 加到 sarvajana 中,就会变成 sarvajanik,但实际发音却是 sárvajanik。

有时在阿拉伯语单词的词根中,如果将动词词根变为名词,则会加上mu,并且第二个辅音也会发生变化。 例如,musháfir指的是“进行一次旅程的人[sháfar]”。 在这种情况下,根据规则,mu会被加在shafar之前,从而变成musháfir。 Mu + shafar = musháfir。 Similarly, mu + hájir = muhájer; mu + sáhib = musáheb. 第二种变化并非语法所致,而是人们造成的。 当阿拉伯语传入印度时,Koráńasharif早已被记录下来。 阿拉伯语语法是在《古兰经》编纂之后才出现的。 孟加拉语中有很多阿拉伯语词汇,但它们出现的时间要晚得多。

英语中也有这类规则。 英语中有一条规则:当出现两个元音时,短元音要位于长元音之后。 在孟加拉语中也是 priiti → piiriti (不是皮里蒂)。 梵语也遵循这一规则。 帕尼尼说,每当有一个辅音出现,且需要延长元音以便发音时,该元音就会变长。 例如,cakśu + roga;其拼写将为cakśúroga。 以同样的方式,ni + rava = niirava。 cakśúroga的ra属于硬ra。 在光速辐射的情况下,这种情况不会发生。

当 “i” 和 “e” 在英语中并排出现时,“i” 会先被发出,因为它的发音时间更长、音量也更大,比 “e” 更明显。 “i”的发音始终为i,而“e” –的发音则有i、e、á –等多种形式,因此“e”出现在“i”之后。 不过,在轻辅音之后可能会出现例外,例如 “ceive”。 此处 “c” 是原来的辅音,因此 “i” 位于动词词根 “ceive” 中 “e” 之后。 当动词词根“ceive”后接不同的前缀时,这一规则依然有效,例如“receive”、“perceive”等等。 “休闲”、“伪造”等情况也是如此。 印地语也遵循其中一些相同的规则,例如 laŕkii,但却是 laŕkián。

(4) 梵语将数分为三种形式:单数、双数和复数。 Lat́ 表示现在时或现在进行时。– 译为:过去时。

(5) “jo”一词指的是“适宜的环境”。 农民们问:这块地有沼气吗? 在纯正的孟加拉语中是jo;在拉尔希孟加拉语中则是batar –,而非bátar。 Bátar意为“瘙痒倾向”,–在梵语中为kańd́úyana。 在梵语中,它的含义是“意味着”。
