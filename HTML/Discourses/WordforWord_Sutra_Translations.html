第1章

1-1 Shivashaktyátmakaḿ Brahma.

Shiva = Puruśa、宇宙的意識とは、文字通り“すべてのものが存在するそのもの”である;Shakti = Prakrti、宇宙的な作用原理とは、文字通り“何かを創造する能力”である;átmakaḿは複合体であり;Brahmaは至高の実在であり、(ブラハトから来ており、“偉大な”ものである。)も同様である。

[Brahmaは、ShivaとShaktiの合成値です。]

1-2 シャクティはSá、シヴァのシャクティである。

Shaktih = 操作原理、宇宙の力、Prakrti; Sá = 彼女、Prakrti; Shivasya (6番目のケース) = Shivaの

[Shakti (操作原理)は、Shivaのshakti (力)です。]

1-3 Tayoh siddhih saiṋcare pratisaiṋcare ca.

tayoh (6番目のケース) = その二つのうちの一つ;siddhih = 証明、実現;saiṋcare (7番目のケース) = saiṋcaraの中にある。saiṋcara = 文字通り“適切な動き”、すなわち微細なものから粗雑なものへと移行する創造の外向的段階:sam (proper) – car (行くため) + ghaiṋ (サフィックス)。pratisaiṋcare (7番目のケース) = 粗雑なものから微細なものへと移行する創造の内向的段階:prati = 反対、逆;ca = そして

[PuruśaとPrakrtiは、saiṋcara (外向的な動き)、pratisaiṋcara、(という物議を醸す運動の中で実現を見る。]

1-4 パラマシヴァはPuruśottamahとして万物の中心にいる。

Parama = 至高のもの;Shivah = 意識;Puruśottamah = 文字通り“最も高次の意識”、創造の核心にある宇宙的意識の名前;vishvasya (6番目のケース) = 宇宙の;kendram = 核心

[宇宙の中心にある至高意識は、ParamashivaまたはPuruśottamaとして知られている。]

1-5 プラヴルッティムクヒー saiṋcarah guńadháráyám.

pravrtti = 欲望、粗野さへの傾向;mukhii = ～へ向かって;saiṋcarah = “適切な動き”;guńa = 縛る原理、属性、特性;dháráyám (7番目のケース) = 流れの中で

[Saiṋcara (宇宙の循環の中で)は、guńas (拘束力のある原則)の影響が強まる中で生じる徐々な外向的な動きである。]

1-6 ニヴルッティムクヒー pratisaiṋcarah guńávakśayeńa.

nivrttimukhii = 欲望が減少する方向への動き:ni (不足) – vrtti (欲望) + mukhii (向かって); pratisaiṋcarah = 宇宙の核へ向かう向心運動;guńa = 結合原理;avakśayeńa (3番目のケース) = 減少することによって

[Pratisaiṋcara (宇宙の循環の中で)は、guńasの影響が弱まる中で生じる徐々な内向的な動きである。]

1-7 Drk Puruśah darshanaḿ Shaktishca.

drk = 目撃者;Puruśa = 宇宙的意識;darshanaḿ = 見る行為;Shaktishca = そしてShakti

[Puruśaは証明者であり、最終的な証人である。(行動能力) Prakrtiは(そして、目撃されるもの)を証明する行為である。]

1-8 Guńabandhanena guńábhivyaktih.

guńa = 結びつける原理;bandhanena (3番目のケース) = 結びつきや束縛によって;guńa = 質;abhi = 良く、完全に;vyaktih = 表現、顕現

[guńasがその束縛を強めるにつれて、根本的な要因の出現において彼らは自らを完全に表現する。]

1-9 Guńádhikye jad́asphot́ah bhútasámyábhávát.

guńa = 縛り、束縛する原理;adhikye (7番目のケース) = 過剰;jad́a = 固形の要素、粗野な物理性;sphot́a = 外部からの過剰な圧力による破裂;bhúta = 文字通り“創造された物体”、五つの根本的要素の一つ;sámya = バランス;abhávát (5番目のケース) = 不存在から

[guńasの過度な圧力により、bhútas (5つの根本的な要因)の間の適切なバランスはlostとjad́asphot́aとなり、(物質の爆発)が生じる。]

1-10 Guńaprabhávena bhútasaungharśádbalam.

guńa = 結合原理;prabhávena (3番目のケース) = 影響によって;bhúta = 生成された対象、根本的要素;saungharśát (5番目のケース) = 冲突から;balam = エネルギー

[guńasの影響が強まることで、基本要素間に衝突が生じ、bala (エネルギー)が生成される。]

1-11 Dehakendrikáńi parińámabhútáńi baláni práńáh.

dehaとは身体、構造のことである。kendrikáńi (形容詞)とは向心運動または慣性運動のことである。parińámabhútáńi (形容詞)とは合力のことである。balániとは力のことである。práńáh (pl.)とは生命エネルギー、つまり多くの力を総称したものである。

[物理的構造内に核を形成し、その結束性を維持する結果として生じる内部力は、práńáh (生命力)と呼ばれる。]

1-12 Tiivrasaungharśeńa cúrńiibhútáni jad́áni cittáńu mánasadhátuh vá.

tiivra = 過度な;saungharśeńa (3番目のケース) = 衝突によって;cúrńiibhútáni = 粉砕された;jad́áni (pl.) = 原始的な要因;cittáńu = 外部プラズマ粒子:citta (精神的客観性) +anu (小さな粒子);mánasa = 心;dhátuh = 物質、要素;vá = または

[過度な衝突により、一部の粗悪な物質が粉砕され、cittáńu (エクトプラズム粒子)、すなわちマインドストッフが生成される。]

1-13 Vyaśt́idehe cittáńusamaváyena cittabodhah.

vyaśt́i = 個体、単位;dehe (7番目のケース) = 構造の中で;cittáńu = 外部プラズマ粒子;samaváyena (3番目) = 組み合わせによって;bodhah = 感覚、感じ

[単位構造内のエクトプラズム粒子の組み合わせによって、citta (客観的な心)という感覚が生まれる。]

1-14 Cittát guńávakśaye rajoguńaprábalye aham. cittát (5番目のケース) = cittaから; avakśaye = 減少期において; rajoguńa = 変化の力; prábalye = 支配状態において; aham = 行動者としての意識、行動者 “I”, または所有者 “I”

[guńasの影響が薄れ、rajoguńaが優勢になるにつれて、aham (行動力)はcittaから進化していく。]

1-15 Súkśmábhimukhiniiはahaḿtattvánmahatを生成する。

súkśma = 微妙なもの;abhimukhinii = ～に向かって;gatir = 動き;udaye = 始まる;ahaḿtattván (5番目のケース) = ahaḿtattvaから;mahat = “I” 感覚

[より微妙なものへとさらに進むにつれて、mahatはahaḿtattvaから進化していく。]

1-16 Cittádahaḿprábalye buddhih.

cittát (5番目のケース) = cittaよりも大きい; ahaḿprábalye (7番目のケース) = ahamが優位なとき; buddhih=知性

[ahamがcittaより大きい場合、buddhi (知性)が変化する。]

1-17 Ahaḿtattvát mahadprábalye bodhih.

ahaḿtattvát (5番目のケース) = ahaḿから来る;mahadprábalye (7番目のケース) = mahatが優位にある時;bodhih = 直感

[mahatがahamより大きい場合、bodhi (直感)が変化する。]

1-18 Mahadahaḿvarjite anagrasare jiivadehe latágulme kevalaḿ cittam.

1-19 Mahadvarjite anagrasare jiivadehe latágulme cittayuktáham.

1-20 Prágrasare jiive latágulme mánuśe mahadahaḿcittáni.

varjiteは「なし」の意であり、anagrasareは「未発達」の意である。jiivadehe (7番目のケース)は「生物や生きている構造物の中」を意味し、latágulme (7番目のケース)は「つる植物や低木の中」を意味する。kevalamは「のみ」を意味し、cittayuktáhamはcittaとahamを含む。prágrasare (形容詞)は「発達した」の意で、mánuśe (7番目のケース)は「人間の中」を意味する。mahadahaḿcittáni (pl.)はmahat、aham、cittaを指す。

[ [[未開発の]]に生息する生物、つる植物や低木の中で、ahamおよびmahatがまだ進化していない場所には、cittaのみが存在する。]

[ [[未開発の]]の生物の中で、mahatがまだ進化していないつる植物や低木の中には、ahamとcittaも存在する。]

[進化した生物、つる植物や低木、そして人間の体内にもmahat、aham、cittaが存在する。]

1-21 Bhúmávyápte mahati ahaḿ cittayorprańáshe saguńásthitih savikalpasamádhih vá.

Bhúmá = 宏大なる心、宇宙的なMahat;vyápte = 滋潤されている;mahati = mahatの中へ;ahaḿcittayor (6番目のケース、二重数) = ahamおよびcittaのもの;prańáshe (7番目のケース) = 解消の中に、saguńa = guńasと共に、限定され、決定されている;sthitih = 状態、savikalpa = vikalpaと共に、または精神的な思考や感情と共に;samádhi = 吸収、目標との一体性:sama (同じ) + adhi (ゴール)

[ahamとcittaがマクロコスミックなMahatに統合されるとき、その統合はsaguńásthitiまたはサヴィカルパsamádhiと呼ばれる。]

1-22 Átmani mahadprańáshe nirguńásthitih nirvikalpasamádhih vá.

átmani = [[から]] Átman、すなわちソウルへ、またはmahadpránashe (7番目のケース) = mahatの解消の中に、nirguńa = guńasはなく、資格なく、不確定である;sthitih = 状態、nirvikalpa = vikalpaがなく、つまり精神的な思考や感情がない;samádhi = 吸収、目標との一体性:sama (同じ) + adhi (ゴール);va = または

[mahatがÁtmanに融合すると、それはnirguńásthiti (無対象性の状態)、またはニルヴィカルパsamádhi(心が不確定な没入状態、あるいは完全な停止状態に陥るトランス)と呼ばれる。].

1-23 Tasyastitih amánasikeśu.

tasya = それの(ニルヴィカルパ samádhiの);sthitih = 状態;amánasikeśu = 心の向こう側

[この状態(ニルヴィカルパ samádhiの)は心の及ばないところにある。]

1-24 Abhávottaránandapratyayálambaniirvrttih tasya pramáńam.

abháva = 虚無; uttara = 後に; ánanda = 臨在; pratyaya = 固い信念; álambaniih = 避難所、支援; vrttih= 心理的傾向; tasya = その(nirguńa sthitiの); pramáńam = 証明

[この虚無の状態の後に残る持続的な至福こそが、その状態の証であり、その状態への確固たる信念を持つための手段である。]

1-25 Bhávah bhávátiitayoh setuh Tárakabrahma.

Bháva = 宇宙的意識の表現であり、振動する思考波によって表出された宇宙である;Saguńa Brahma;Bhávátiita = bháva、Nirguńa Brahmaを超えている;tayoh = その二つのうちの一つ;setuh = 橋;Táraka = 解放するもの、人が渡るのを助けるもの

[Nirguńa BrahmaとSaguńa Brahmaの間の橋は、Táraka (解放する) Brahmaと呼ばれます。]

第2章

2-1 Anukúlavedaniiyaḿ スカム。

anukúla = 調和のとれた状態;vedaniiyaḿ = anáhata cakraにおけるヨーガ的な心の感覚;sukham = 楽しみ、幸福、緊張した神経が正常に戻るときの感覚

[心地よい心の状態を幸福と呼ぶ。]

2-2 Sukhánuraktih paramá jaeviivrttih.

sukha = 幸福;ánuraktih = 愛情、恋愛、献身、渇望:anu – rańj (色) + ktin (心が望む物体の振動色の影響によって生じる、心の色の変化を指す);paramá = 最高の;jaevii = 生き物;vrttih = 性向

[幸福への執着こそが、生き物たちの根本的なvrtti (傾向性)である。]

2-3 Sukhamanantamánandam.

sukha = 幸福;anantam = 無限の;ánandam =至福 [無限の幸福とはánanda (至福)なのです。]

2-4 Ánandaḿ Brahma ityáhuh.

ánandaḿ =至福、Brahma =至高意識、ityáhuh =と呼ばれる:iti + áhuh (文字通り、“このように言われている”)

[このánandaはBrahmaと呼ばれます。]

2-5 タスミンヌパルブデ paramá trśńánivrttih.

tasmin = それにおいて;upalabdhe (7番目のケース) = 達成の瞬間に;paramá = 最高の、主要な;trśńa = 渇き;nivrttih = 完全な満足、欲望の終わり

[(Brahma)を得ることで、あらゆる渇きは永遠に癒される。]

2-6 Brhadeśańáprańidhánaḿ はダルマなり。

Brhat = 偉大なる;eśańa = 愿望およびそれを達成するための努力;prańidhánaḿ = 追い求めること;ca = そして;dharmah = 根本的な特性

[偉大なものを渇望し、追い求めることこそがdharmaである。]

2-7 Tasmáddharmah sadákáryah.

tasmád (5番目のケース) = したがって、文字通り“その”からである;dharmah = 根本的な特性;sadá = 常に;káryah = 実践されるべきもの

[したがって、dharmaは常に実践されるべきである。]

2-8 Viśaye puruśávabhásah jiivátmá.

viśaye (7番目のケース) = オブジェクト内に;Puruśa = 意識、avabhásah = 反省;jiivátmá = 個の魂

[単位オブジェクトにおけるPuruśaの反射は、jiivátmá (ユニットソウル)と呼ばれる。]

2-9 Átmani sattásaḿsthitih.

átmani = átmanの中にある;sattá = エンティティ;saḿsthitih = それと共に存在し、最終的に実証される

[すべてのエンティティは最終的にÁtmanに組み込まれる。]

2-10 Otahprotah yogábhyáḿ saḿyuktah Puruśottamah.

otah = 個体;protah = 集団;yogábhyáḿ (二重の) = 2種類の結合によるもの;saḿyuktah = 接続されている;Puruśottamah = 宇宙核

[Puruśottamaは、各エンティティと個別に、またすべてのエンティティと総合的にリンクされている。]

2-11 Mánasátiite anavastháyaḿ jagadbiijam.

mánasátiite = 心の及ばないところ;anavastháyáḿ (7番目のケース) = 存在しない状態;jagat = 宇宙;biijam = 種子

[宇宙の種子は心の外側、心が理解できない状態にある。]

2-12 Saguńát srśt́irupattih.

saguńát (5番目のケース) = 修練された意識から来るもの;srśt́ir = 創造;utpattih = 起源、誕生

[その創造はSaguńa Brahmaに由来する。]

2-13 Puruśadehe jagadábhásah.

Puruśa = 意識;dehe (7番目のケース) = 身体の中、構造の中に;jagat = 宇宙;ábhásah = 反射、外見、姿形

[宇宙は認知体の中で形を成す。]

2-14 Brahma Satyaḿ jagadapi satyamápekśikam. satyaḿ = truth, unchanging; jagat = universe; api = also; ápekśikam = relative

[Brahmaこそが絶対的な真理であり、宇宙もまた真理だが、それは相対的なものである。]

2-15 Puruśah akartá phalasákśiibhútah bhávakendrasthitah guńayantrákashca.

Puruśah = 意識;akartá = 行為者でない者;phala = 果実、行為の結果;sákśii = 目撃者;bhútah = 实在体;bháva = 存在、Saguńa Brahma;kendra = 核;sthitah = 状態、位置;guńayantrakashca = そしてguńasの制御者

[Puruśaは何の行動も取らない。(そのまま)も同様だが、行動や反応の証人となる存在であり、Saguńa Brahmaの核に位置している。彼はguńasの制御者である。]

2-16 Akartrii viśayasaḿyuktá buddhih mahadvá.

akartrii = 行為を行わない者;viśaya = 対象物;saḿyuktá = ～と関連し、結合している;buddhih mahadvá = buddhitattva または mahattattva

[buddhitattva、またはmahattattva自体は実行主体ではなく、対象物と関連しているだけである。]

2-17 Ahaḿ kartá pratyakśaphalabhoktá.

ahaḿ = doer “I”; kartá = doer; pratyakśa = direct; phala = fruit, results of action; bhoktá = enjoyer (つまり、行動の結果を得る者だ)

[ahamこそが行為者であり、行為の結果を直接享受したり苦しんだりするのである。]

2-18 Karmaphalaḿ cittam.

karma = 行動;phalaḿ = 行動の結果である果実;citta = 目標 “I”

[cittaは、行動の結果の形をとる。]

2-19 ヴィクルタチッタシャー púrvávasthápráptirphalabhogah.

vikrta = 変化した、転換された、変更された;cittasya (6番目のケース) = cittaの;púrva (形容詞) = 以前の;prápti = 成就、達成;phala = 果実、行為の結果;bhogah = 楽しみ (あるいは苦しみ)

[歪んだcittaが元の状態に戻る過程とは、行為の結果によって喜びや苦しみを味わうことである。]

2-20 rasátalahへと天へ。

na = いいえ; svargo = 天国; rasátalah = 地獄

[天も地獄も存在しない。]

2-21 Bhúmácitte saiṋcaradháráyáḿ jad́ábhásah.

Bhúmácitte = 宏大なcittaの中にある;saiṋcara = 外向的な動き;dháráyáḿ (7番目のケース) = 流れの中にある;jad́a = 物質;ábhásah = 反射、外見、姿形

[saiṋcaraの流れの中で、物質は宇宙のcittaの中に形を成す。]

2-22 Bhútalakśańátmakaḿ bhútabáhitaḿ bhútasaungharśaspandanaḿ tanmátram.

bhúta = 生成された対象、根本的要素;lakśańa = 符号または印;átmakam = ～で構成される;báhitam = ～によって運ばれる;saungharśa = 衝突;spandanam = 振動;tanmátram = “の極めて微小な量または分数であり” (根本的な要因のうち)、超感覚的推論、一般的本質:tan (それは) + mátra (ごくわずかな量)

[Tanmátras (bhútasの微小な断片、または根本的な要因)はbhútasを表し、bhútasによって運ばれ、bhútas内の衝突による振動によって生成される。]

2-23 Bhútaḿ tanmátreńaが参加します。

bhútaḿ = 基本的な要因;tanmátreńa (3番目のケース) = tanmátrasによって;pariciiyate = 認識されるか知られている

[bhútasは、対応するtanmátrasによって認識される。]

2-24 Dvárah nád́iirasah piit́hátmakáni indriyáńi.

dvárah = 入口、ゲートウェイ;nád́ii = 神経;rasah = 液体;piitha = 制御点、つまり脳内でcittaに接続された器官の位置;átmakáni = ～で構成される;indriyáńi (pl.) = 器官

[インドリヤである(器官)は、器官の門、神経、神経液、そして器官(脳の中で)の適切なpiit́has (座席)によって構成されている。]

第3章

3-1 Paiṋcakośátmiká jaeviisattá kadaliipuśpavat.

paiṋca = 五;kośa = 層、外被;átmiká = ～で構成される;jaeviisatta = 生き物;kadalii = バナナの木;puśpavat (5番目のケース) = 花のように

[生き物とは、バナナの花のように5つのkośas (心の層)から構成されるものである(その花びらと共に)。]

3-2 Saptalokátmakaḿ ブラフマーマナハ。

sapta = 七;loka = 地域、領域;átmakaḿ = で構成される;manah = 心

[宇宙の心とは、七つのローカスが結合したものである (層、世界)。]

3-3 Kárańamanasi diirghanidrá marańam.

káráńa = 因果的;manasi (7番目のケース) = 心の中で;diirgha = 長い;nidrá = 睡眠;marańam = 死亡

[因縁の心の中での長い眠りは死である。]

3-4 マノヴィクリティー vipákápekśitá saḿskárah.

manovikrtih = 心理的歪み;vipáka = 反応;apekśitá = 表出すべき、潜在的なもの;saḿskárah = 潜在性における反応

[表現を待つ精神物質の歪みである(つまり、潜在的な反応である。)は、saḿskáraとして知られている。]

3-5 Videhiimánase na kartrtvaḿ na sukháni na duhkháni.

videhiimánase (7番目のケース) = 非物質的な心の中に;na = いいえ;kartrtvaḿ = 行為性;sukháni = 楽しみ;duhkháni = 痛み

[無形の心には行為者としての姿も、喜びや痛みの感覚も存在しない。]

3-6 Abhibhávanát cittáńusrśt́apretadarshanam.

abhibhávanát (5番目のケース) = 集中した思考から生じるもの;cittáńu = 心の中のもの;srśt́a = 設計されたもの;preta = 幽霊;darshanam = 視覚

[幽霊の姿は、集中した思考におけるcittáńu (心の中身)によって生み出される。]

3-7 Hitaeśańápreśito'pavargah.

hita = 福祉、全面的な発展;eśańá = 意欲、意志;preśitah = 動機付けられた;apavargah = 行為の報い、行為が完了した後の時期

[ある行為の報いは、福祉への(神聖なる)の渇望によって導かれる。]

3-8 Muktyákáuṋkśayá sadgurupráptih.

mukti = 解放;ákáunkśayá (3番目のケース) = 強烈な願望によって;sadguru = 完璧な師;práptih = 達成、成果

[mukti (解放)への強い渇望から、人は自らのサドグルである(完璧な達人)を得るのである。]

3-9 ブラフマーこそが真の師なり náparah.

Brahmaeva = Brahmaのみ; guruh = グル; ekah = 一つ; na = いいえ; aparah = その他

[Brahmaだけがグルだ、他にはいない。]

3-10 Bádhá sá yuśamáná shaktih sevyaḿ sthápayati lakśye.

bádhá = 障害物; sá (女性) = それ; juśamána = 助けること; shaktih = 力; sevyaḿ = [[提供されるに値する]]である者; sthápayati = 設立する者; lakśye (7番目のケース) = 目標の中で、目的の中で

[障害とは、人を目標へと導く助けとなる力である。]

3-11 Prárthanárcanámátraeva bhramamúlam.

prárthana = prayer; árcaná = worship; mátraeva =certainly only; bhrama = error; múlam = root, cause

[祈りと儀式的な崇拝は混乱の原因となる。]

3-12 Bhaktirbhagavadbhávanáからstutirnárcanáまで。

bhaktih = 献身;Bhagavad = 神;bhávaná = 思考;na = いいえ、ない;stutih = 賛美、賛歌;arcaná = 崇拝

[献身とは神について思索することであり、神をお世辞で褒め称えたり、儀式的に崇拝したりすることではない。]

第4章

4-1. Triguńátmiká srśt́imátrká asheśatrikońadhárá.

triguńa = 3つのguńas または拘束的な原則; átmiká = ～で構成される; srśt́i = 創造; mátriká = 母; asheśa = 無限; trikońa = “3つの角”, 三角形; dhárá = 流れ

[三重属性を持つ根源的な力(創造の母)は、終わりのない三角形の形で流れ続けている。]

4-2. Tribhúje Sá svarúpaparińámátmiká.

tribhúje (7番目のケース) = 三角形の中に;Sá = 彼女、Prakrti;svarúpa = 実際に“独自の形態”、自己存在;parińáma = 変化;átmika = ～で構成されている

[力の三角形の中で、Prakrtiの3つの属性は終わりなき相互変化の中に閉じ込められている。]

4-3. Prathamá avyakte Sá Shivánii kendre ca Paramashivah.

prathamá = 最初のもの;avyakte (7番目のケース) = 表現されていない状態にある;Sá = 彼女、Prakrti;Shivánii = 第一段階におけるPrakrtiの名前 (Shivaの女性形);kendre (7番目のケース) = 核の中にある;ca = そしてParamashivah = 最高意識、Puruśaの名前

[最初の段階(まだ実際の顕現の段階には至っていない)において、PrakrtiはShivániiと呼ばれ、核内にある証人となるPuruśaはParamashivaと呼ばれる。]

4-4. Dvitiiyá sakale prathamodgame Bhaeravii Bhaeraváshritá.

dvitiiyá = 第二;sakale = 柔らかい音を持つ;prathama = 第一;udgame (7番目のケース) = 芽生える;Bhaeravii = 第二段階におけるPrakrtiの名前 (バエラヴァの女性形);Bhaerava = 第二段階におけるPuruśaの名前;áshritá = 保護された

[第二段階において、進化の種が芽生えると、Prakrtiはバエラヴィーと呼ばれ、それを見守るPuruśaはバエラヴァと呼ばれる。]

4-5. Sadrshaparińámena Bhavánii Sá Bhavadárá.

sadrsha = 類似のもの; parińámena (3番目のケース) = 結果から得られたもの; Bhavánii = この段階におけるPrakrtiの名称 (Bhavaの女性形); Sá = 彼女、Prakrti; Bhavadárá = Bhavaの妻 (Puruśa)

[振動の世界には、曲率の類似性からなる一連のパターン(同質化)が存在する。 ここではPrakrtiはBhavániiと呼ばれ、証人となるPuruśaはBhavaと呼ばれる。]

4-6. Shambhúliuṋgát それがその行為である。

Shambhú = 自己で作成したコントローラー;liuṋgát (5番目のケース) = 符号や記号から来たもの;tasya = その、彼の;vyaktih = 表現

[創造のプロセスはShambhúliuṋgaから始まる。]

4-7. Sthúliibhavane nidritá sá kuńd́alinii。sthúliibhavane (7番目のケース) = 未完成の段階にある;nidritá = 眠っている;sá = 彼女;kuńd́alinii = 蛇のように丸まっている

[最終的な粗悪化の段階において、Svayambhúliuṋga内で休眠状態にあるparáshaktiはkuńd́alinii (“螺旋状の蛇のような形”)と呼ばれる。]

4-8 Kuńd́alinii sá múliibhútá rńátmiká.

kuńd́alinii = literally “coiled serpentine”; sá = she; múliibhútá = fundamentally; rńátmiká = negative

[kuńd́aliniiとは、(力の強さ)の根本的な負性である。]

第5章

5-1. Varńapradhánatá cakradháráyám.

varńa = 色 (ここに、心の色がある。); pradhánatá = 優勢; cakra = “サイクル”, 社会的サイクル; dháráyám (7番目のケース) = 流れの中で

[社会の循環の中で、常にある一つの階級が支配的である。]

5-2. チャクラケンドレ sadvipráh cakraniyantrakáh.

cakrakendre (7番目のケース) = 社会循環の核心において;sadviprah (pl.) = 実際に“真実 vipras”である;cakra = 循環;niyantrakáh = 制御装置

[社会循環の核心に位置するサドヴィプラスが、社会循環をコントロールしている。]

5-3. Shaktisampátena cakragativardhanaḿ krántih.

shakti = 力; sampátena (3番目のケース) = 適用によって; cakra = サイクル; gativardhanaḿ = 動きを加速させるために; krántih = 進化: kram (何らかの障害を乗り越えるために)

[力を加えることによって社会の循環の動きを加速させることを“進化”と呼ぶ。]

5-4. Tiivrashaktisampátena gativardhanaḿはヴィプラヴァです。

tiivra = 巨大で、突然に起こり、激しいもの;shakti = 力;sampátena (3番目のケース) = 実施によって;gativardhanaḿ = 動きを加速させるために;viplavah = 文字通り“すべてを覆い尽くす流れ”、つまり革命

[莫大な力を用いて社会の循環の動きを加速させることを“革命”と呼ぶ。]

5-5. Shaktisampátena vipariitadháráyáḿ vikrántih.

shakti = 力; sampátena (3番目のケース) = 適用によって; vipariita = 反対; dháráyáḿ (7番目のケース) = 流れの中で; vikrántih = 逆進化

[力を用いて社会の循環の流れを逆転させることを“逆進化”と呼ぶ。]

5-6. Tiivrashaktisampátena vipariitadháráyaḿはプラティヴィピラヴァです。

tiivra = 巨大な;shakti = 力;sampátena (3番目のケース) = 実践を通じて;vipariita = 反対の;dháráyáḿ (7番目のケース) = 流れの中で;prativiplavah = 反革命

[莫大な力を用いて社会の循環の流れを逆転させることを“反革命”と呼ぶ。]

5-7. Púrńávartanena parikrántih.

púrńa = 完了状態;ávartanena (3番目のケース) = 旋回または回転を伴う状態;parikrántih = 循環運動の完了状態

[社会循環の完全な一回転は、“周辺的進化”と呼ばれる。]

5-8. Vaecitryaḿ prákrtadharmah samánaḿ na bhaviśyati.

vaecitryaḿ = 多様性、色彩豊かさ;prákrta = 自然な、Prakrti (最高の作戦原則)に関連するもの;dharmah = 特徴、根本法則;samánaḿ = 互いに異なる二つの対象が持つ質的・量的価値の等しさ;na = いいえ、ない;bhaviśyati = なるであろう

[多様性こそが自然の法則であり、アイデンティティではない。]

5-9. Yugasya sarvanimnaprayojanaḿ sarveśáḿ vidheyam.

yugasya (6番目のケース) = 長年にわたるもの;sarvanimnaprayojanaḿ = 最低限の必需品;sarveśáḿ = あらゆるもの;vidheyam = 提供されるべきである

[すべての人に年齢に関する最低限の要件が保証されるべきである。]

5-10. Atiriktaḿ pradátavyaḿ guńánupátena.

atiriktaḿ = 余剰在庫;pradátavyaḿ = 提供すべきもの;guńánupátena = 实力に応じて

[余剰な富は、功績の度合いに応じて功績のある人々の間で分配されるべきである。]

5-11. Sarvanimnamánavardhanaḿ samájajiivalakśańam.

sarvanimnamána = 最低限の生活水準;vardhanaḿ = 増加;samájajiiva = 社会の活力;lakśańam = 指標、兆候

[人々の最低限の生活水準を向上させることは、社会の活力の指標である。]

5-12. Samájádeshena viná dhanasaiṋcayah akartavyah.

samája = 社会;adeshena (3番目のケース) = 指示や命令を与えること、承認によって;viná = なしで;dhana = 財富;saiṋcayah = 積み重ね;akartavyah = 行うべきではない

5-13. Sthúlasúkśmakárańeśu caramopayogah prakartavyah vicárasamarthitaḿ vańt́anaiṋca.

sthúla = 平凡で粗雑なもの;súkśma = 超自然的で、原子構造に関連するもの;kárańeśu (第7のケース 複数形) = 原初的な因果要因;carama = 最大;upayogah = 利用;prakartavyah = 何の逸脱もなく厳格に行われるべきもの;vicára = 理性的な判断、良心によって支えられる判断;samarthitaḿ = ～によって支えられる;vańt́anam = 分配;ca = そして

5-14. Vyaśt́isamaśt́isháriiramánasádhyátmikasambhávanáyáḿはカラモパヨガシュカです。

vyaśt́i = 個人;samaśt́i = 集団;sháriira = 肉体 (ここでは個人と集団の両方);mánasa = 心霊体 (個人も集団も);ádhyátmika = átmáの、霊的体 (個人も集団も);sambhávanáyáḿ = 既に獲得された、または今後獲得可能な潜在能力;carama = 最大値;upayogah = 利用;ca = そして

5-15. Sthúlasúkśma kárańo’payogáh susantulitáh vidheyáh.

sthúla = (ここに)はいずれも世俗的かつ物理的なものであり、súkśma = (ここに)はいずれも精神的かつ超世俗的なものである。kárańaは霊的な、根源的な因果要因であり、upayogáh (pl.)は利用であり、susantulitáh (pl.)はバランスが取れており、vidheyáh (pl.)は適切に行われるべきである。

5-16. Deshakálapátraeh upayogáh parivarttante te upayogáh pragatishiiláh bhaveyuh.

deshakálapátraeh = 空間、時間、人間;upayogáh = 利用;parivarttante = 変化する;te = それらの;upayogáh = 利用形態;pragatishiiláh = 進行的な;bhaveyuh = すべき、または必要な

Pragatishiila upayogatattvamidaḿ sarvajanahitárthaḿ sarvajanasukhárthaḿ pracáritam.

pragatishiila = 进歩的な;upayoga = 利用;tattvam = 理論;idaḿ = これ;sarvajana = すべての人々;hitárthaḿ = 全面的な福祉と安寧のために;sukhárthaḿ = 全面的な幸福のために;pracáritam = 宣伝されている

[これが進歩的利用理論であり、すべての人々の幸福と全面的な福祉のために提唱されたものです。]
